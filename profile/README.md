## 🧬 What I'm Building

**NeoTrix** — an AI-native developer toolkit with self-evolving reasoning.

> Not an IDE plugin. Not an LLM wrapper. A cognitive operating system.

Instead of probabilistic next-token prediction, NeoTrix runs a **deterministic 64-state
E8 reasoning engine**, routes attention through **Global Workspace Theory**, stores
knowledge in a **4096-dim VSA HyperCube**, and improves its own reasoning via the
**SEAL self-evolution loop**.

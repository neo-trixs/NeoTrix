## 何时用 / 何时不用

- 用：新界面要 2 个以上方向；已有方向要评审；用户说"不要千篇一律"；截图还原；视觉精修。
- 不用：纯组件实现（→ `ui-skill`）；品牌身份与设计语言体系（→ `visual-taste-lab`）；
  纯业务逻辑、无界面行为变化的代码整理（oil-ui 原文即排除此类）。

## 工作流（5 步，源自 oil-ui 方法论，保留其编号与术语以便对照上游）

### 1. 探索并收敛方向（详见 `references/design-direction.md`）

- **先定调性**：能量/完成度/密度/分量/严肃度五个刻度，每个写依据。
  模糊词（高级/精致/克制/史诗/文学感/简洁）必须先翻译成可观察决定，否则从理由里删掉。
- **生成引擎起方向**（不用形容词起）：材质×环境、具体场景、角色原型、设计运动、
  跨领域表现形式、故意破常规。每个方向一句话北极星。
- **先定首屏骨架再写文案**：8 种骨架（满版图像压字/居中单物件/画面即界面/满版文字/
  通栏堆叠/网格拼贴/纵排斜向/左右分栏）；**同一轮骨架互不相同，左右分栏至多一个**
  （模型默认即左右分栏，必须显式压住）。
- **方向卡**：北极星/调性/引擎/骨架+线框/页面结构/各区块形式/字体/色彩（十六进制）/
  主视觉/图标/结构性突破/放弃什么 —— 填具体选择，不填形容词。
- **差异检验**（做小样前必过）：比线框不比描述；四项（骨架/字体/色彩/主视觉）
  任意两方向至多一项相同；不按明暗分方向；至少一个走极端、一个打破品类套路；盲看可辨。
- **用户定品味**：对比页或方向清单 + 推荐理由请用户选；追问具体喜欢/不喜欢；
  选定方向写入设计说明作后续基线。

### 2. 建立视觉与交互结构（详见 `references/visual-language.md`）

- 焦点与空间：每区域一个主角；间距分组；容器/分隔线只在确有分组时出现，不逐层套卡片。
- 字体与内容：中文排版单独验证（行高/断行/窄屏），英文样例好看不证明中文成立；
  **可读性是交付门槛**（正文 14–16px 起，行高 1.6–1.75）。
- 色彩与表面：按含义用色；质感按调性取用不混用；配色做"去发光仍成立"自检。
- 控件与图标：状态完备（默认/按下/聚焦/选中/禁用/处理中），悬停不替代触屏键盘入口。

### 3. 制作并取得实际证据

- 代表性页面先行；示例内容按真实产品写；**画面上不出现"示例/待核实/示意图"类制作说明**；
  不伪造业务成功与指标（与本仓 silent-failure 纪律同构：失败不伪装成功）。
- 真实视口运行 + 截图（页面/状态/视口/版本）；中文标题窄屏换行必查。

### 4. 独立评审（详见 `references/visual-review.md`）

- **隔离评审者**：新上下文，只给当前画面+任务+约束，不给制作历史与旧评分；
  不能看图时只做结构诊断、不猜画面、不打虚假分数。
- 评审任务：说出体裁→设想顶尖团队做法→指出差距最大的 1–3 处→10 分制打分（附具体差距）。
- 主 Agent 处理反馈：先修任务阻碍，再修精修；"可直接删掉的文字"默认照删；
  建议违反约束或纯偏好时可不采纳并留理由；**出现换风格循环即停止**，保留最合适版本。

### 5. 验证与交付

- 对照任务+方向检查真实内容/视口/状态；交互走通；用项目现有门禁。
- **单独做一次减法**：一页一个主角；逐区块删一轮文字，只放回删了影响理解的。
- 交付文件或预览 + 设计说明（方向/变化/验证/剩余项）；没做的步骤写没做和原因。

## 风格对比页生成器（`scripts/build_explorer.py`）

- 用法：`python3 scripts/build_explorer.py <任务目录>/manifest.json --output <任务目录>/style-explorer.html`
  （要求 Python ≥3.10；默认拒绝覆盖，更新加 `--force`）。
- manifest 字段见 `references/style-explorer.md`（schemaVersion/candidates，
  kind ∈ html/image/url，url 仅限本机回环地址）。
- 安全 posture（上游内置，本次吸收逐项核实源码）：CSP 注入、无 iframe/embed、
  资源必须内嵌（base64）、url 仅 localhost/127.0.0.1/::1、不写 Skill 安装目录、
  原子更新（tempfile+replace）、fingerprint 防旧选择误用。
- 回归：`python3 -m unittest discover -s tests -v`（上游 18 个，本会话引入位置复跑通过）。

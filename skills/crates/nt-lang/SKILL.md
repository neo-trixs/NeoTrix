# nt-lang

## Purpose
NeoTrix 语言编译器

## Trigger Words
- nt-lang
- language
- compiler
- 编译器
- DSL
- 领域特定语言

## Content
- 中间表示 (IR)
- 代码生成 (codegen)
- Rust 后端
- 测试解析器

## Commands
```bash
nt-lang build <file.nt>    # 编译单个文件
nt-lang build-all          # 编译所有文件
```

## Location
`crates/nt-lang/`

## Usage
用于编译 NeoTrix 领域特定语言文件。

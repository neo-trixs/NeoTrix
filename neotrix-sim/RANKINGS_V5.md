## Cross-Topic Observations

### Key Trends
- **AI Agents dominate Rust trending** — codex, rtk, agent-browser, cc-switch all >10k stars
- **Bevy ecosystem** is the dominant Rust game engine (48.1k stars), with strong physics (avian), networking (lightyear), and AI (big-brain) plugins
- **Tauri** has massive adoption for desktop apps — cc-switch (132k), NextChat (88.7k), Pake (61.4k)
- **Agent-based modeling** is converging with LLMs — AgentSociety (Tsinghua) and TimeCopilot use LLM-native approaches
- **traffloat** (26★) is the only Rust/Bevy simulation-game — potential integration point for NeoTrix
- **krABMaga** (220★) is a Rust-native ABM framework — relevant for NeoTrix's simulation capabilities

### NeoTrix Relevance
| Signal | Project | Relevance |
|--------|---------|-----------|
| ECS for ABM | krABMaga, Agents.jl, AgentTorch | Validate NeoTrix's ECS-based simulation approach |
| Bevy + Simulation | traffloat, avian, big-brain | Potential rendering/physics layer for NeoTrix sim |
| LLM + ABM | AgentSociety, TimeCopilot, mesa | Converges with NT-MIND's self-evolution patterns |
| Desktop UI | cc-switch, opcode, Seelen-UI | Tauri stack for NeoTrix desktop experience |
| Agent Frameworks | rig, nerve, awesome_ai_agents | Agent orchestration patterns for NT-ACT |

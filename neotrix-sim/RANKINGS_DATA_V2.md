## 7. Key Insights & Trends

### 7.1 Scale Explosion
- 2023: 25 agents (Stanford Generative Agents)
- 2024: 1K-100K agents (OASIS, GenSim, AgentSociety)
- 2025: 1M-1B agents (Light Society, Agent-Kernel)
- **Trend**: Scaling laws emerge at larger agent populations

### 7.2 Architecture Convergence
- **Memory**: All top frameworks implement retrieval + episodic memory
- **Planning**: LLM-based reasoning replacing rule-based systems
- **Communication**: Natural language → MQTT/message-passing for scale
- **Environment**: From text-only to physical (UE5, Bevy ECS)

### 7.3 Rust Renaissance
- New wave of Rust simulation frameworks: SpaceProjectSim, AgentVerse, Terrarium, RESONANCE, Vireo, Syren-ABM, Kairos
- GPU-accelerated ALife: Ribossome (wgpu), Vireo (WGPU)
- Bevy ECS emerging as preferred game engine for sim frameworks

### 7.4 Key Gaps for NeoTrix
1. **No unified Rust ABM framework** with LLM integration + GPU + memory
2. **No cross-domain simulation** (social + physical + economic + evolutionary)
3. **No self-evolving architecture** in existing frameworks
4. **Memory is immature everywhere** — no production-grade long-term memory with semantic search
5. **Context rot awareness** — universal gap across all frameworks

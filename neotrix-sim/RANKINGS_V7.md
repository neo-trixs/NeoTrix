## 5. pollen-robotics/microduck_rl — Spotlight Repo

| Field | Value |
|-------|-------|
| **Repository** | [pollen-robotics/microduck_rl](https://github.com/pollen-robotics/microduck_rl) |
| **Stars** | 2.0k |
| **Forks** | 416 |
| **Language** | Python (mjlab / MuJoCo Warp) |
| **License** | Apache 2.0 |
| **Description** | RL training environments for Microduck — a ~800g, ~25cm tall bipedal robot |

### Key Capabilities
- **PPO-based** walking policies trained at 50 Hz via MuJoCo Warp
- **Sim2Real pipeline**: BAM actuator physics, domain randomization, backlash simulation
- **13 task variants**: Velocity, VelStand, StandUp, SitStand, GroundPick, BallKick, Roulade, Roller tasks, Spin
- **Policy hot-swapping**: Runtime swaps walk/recover/trick policies behind shared 61-dim observation
- **ONNX export** → deployment on real Microduck robot
- **Backlash variants**: Every main task has a ±1° gear play twin

### Notable Design Patterns
- Shared 61-dimensional observation contract across all policies
- BAM M6 actuator model (voltage control + load-dependent friction)
- Domain randomization on battery voltage, voltage sag, command delay, friction
- 14 servo joints (5 left leg, 4 neck/head, 5 right leg)
- Hugging Face Jobs integration for cloud training

## 6. Featured Repo — microduck_rl

| Field | Value |
|-------|-------|
| **Repo** | [pollen-robotics/microduck_rl](https://github.com/pollen-robotics/microduck_rl) |
| **Stars** | 2,000 |
| **Forks** | 415 |
| **License** | Apache 2.0 |
| **Language** | Python (MuJoCo Warp + PPO) |
| **Description** | RL training environments for Microduck — a ~800 g, ~25 cm tall bipedal robot |
| **Key Tech** | mjlab (MuJoCo Warp), BAM actuator physics, domain randomization, sim2real transfer |
| **Training** | 4096 envs, ~1-2 h for usable gait, GPU required, ONNX export for deployment |
| **Tasks** | 13+ envs: Velocity, VelStand, StandUp, SitStand, GroundPick, BallKick, Roulade, Roller variants, Spin |
| **Observation** | 61-dim shared across all policies (48 proprioception + twist(3) + head_pose(4) + body_pose(6)) |
| **Joint Layout** | 14 servos: 0–4 left leg, 5–8 neck/head, 9–13 right leg |
| **Sim2Real** | BAM M6 XL330 voltage control + back-EMF + Coulomb/Stribeck/load-dependent friction |
| **Backlash** | ±1° gear play variants for sim2real fidelity |
| **Publishing** | `uv run publish` → HuggingFace Hub with baked-in obs normalizer + manifest.json |
| **Related** | [microduck](https://github.com/pollen-robotics/microduck) (runtime), [mjlab](https://github.com/mujocolab/mjlab) (training), [BAM](https://github.com/Rhoban/bam) (actuator models) |

## Cross-Topic Observations

1. **Tauri dominance in desktop AI tools** — cc-switch (132K), NextChat (88.7K), Pake (61.4K) show Tauri as the default framework for AI-native desktop apps.
2. **Rust trending = developer tooling** — rtk (LLM token reduction), ruff (Python linting), zoxide (cd), jj (VCS) dominate weekly Rust trending.
3. **Bevy ecosystem maturing** — avian (physics), lightyear (networking), big-brain (utility AI) fill core engine gaps.
4. **Game AI = card games + navmesh** — DouZero, rlcard, Mortal (mahjong), recastnavigation dominate; mahjong AI is a strong Rust niche.
5. **RL landscape = educational + infra** — cs-video-courses, annotated papers, d2l book are the star leaders; actual RL frameworks (ray, openrl) trail in stars.
6. **microduck_rl = sim2real pioneer** — BAM actuator physics + domain randomization for 800g bipedal robot; shared 61-dim obs contract enables runtime policy hot-swapping.

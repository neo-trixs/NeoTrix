## 8. Key Insights

### Ecosystem Health
- **Bevy dominates** with 48.1k stars, 609k downloads for bevy_ecs, and the largest plugin ecosystem (1,484+ Rust repos tagged bevy)
- **Fyrox** is the only Rust engine with a full visual editor, filling the Unity-like niche
- **macroquad** excels for rapid prototyping and WASM deployment
- **ggez** remains the stable choice for simple 2D games

### ECS Landscape
- **bevy_ecs** (609k downloads) is the de facto standard Rust ECS
- **hecs** (39k stars) is the go-to standalone ECS for non-Bevy projects
- **specs** is mature but development has slowed
- **legion** and **shipyard** are actively maintained alternatives

### Physics
- **avian** (3.2k stars) is the primary Bevy physics solution, replacing the older rapier-bevy
- **rapier3d** (108k downloads) is the standalone physics engine

### Simulation
- **madsim-tokio** (108k downloads) dominates async simulation/testing
- **embedded-graphics-simulator** (9.4k) is the standard for embedded dev
- Most Rust simulation frameworks are domain-specific (molecular, celestial, fluid)

### WASM Support
- **Bevy** and **macroquad** have the best WASM support
- **ggez** supports WASM but with less ecosystem integration
- **Fyrox** does not currently support WASM

### Editor Support
- Only **Fyrox** has a built-in visual editor in the Rust ecosystem
- **Godot-rust** leverages Godot's editor but is not pure-Rust
- All other Rust engines are code-only

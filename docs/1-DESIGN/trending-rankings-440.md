## Trending Patterns (Sep 2026)

### 1. Multi-Agent Coordination Memory
Lore, Mycelium, CogniHive, Kronaxis Fabric all converge on **shared agent memory** as the critical gap. The pattern: agents need read-your-writes consistency, expertise routing, and conflict resolution — not just vector search.

**NeoTrix mapping**: NT-MEMORY `kv_store` experience namespace + ConsciousnessTree branch routing.

### 2. Pre-Inference / Pre-Cognitive Routing
Cardiac Architecture routes decisions from accumulated experience *before* LLM reasoning. Sprix SAGE does state-aware SELF/COLLABORATE/HANDOFF. Both reduce inference cost by routing familiar tasks without full reasoning passes.

**NeoTrix mapping**: GWT salience with cost-aware routing (Axiom A1). E8 hexagram as pre-cognitive routing table.

### 3. Self-Improving Agent Harnesses
Prime Agent's Continual Harness (`/refine` applies evidence-backed updates) and BetterClaw's graduated trust levels both implement **incremental capability improvement** without retraining.

**NeoTrix mapping**: SEAL pipeline self-evolution + SelfModel dynamic performance tracking.

### 4. Test-Time Compute Efficiency
TRACE (temporal reasoning aggregation), AERA (adaptive evidence residual allocation), Prefix Sliding, SeerSC all attack the same problem: **don't waste tokens on problems you've already solved**. Key insight: confidence ≠ correctness; need temporal evidence aggregation.

**NeoTrix mapping**: NT-CORE reasoning loop with adaptive depth (RecurTrace analog) + NT-MEMORY experience caching to skip re-reasoning.

### 5. Protocol Consolidation: MCP + A2A
MCP for tool communication, A2A for agent-to-agent. ACP absorbed into A2A. Both now under Linux Foundation. Production pattern: A2A for orchestration, MCP for execution.

**NeoTrix mapping**: NT-IO provider routing already implements MCP-like tool abstraction. A2A integration for cross-domain agent coordination (ConsciousnessTree branches communicating via A2A).

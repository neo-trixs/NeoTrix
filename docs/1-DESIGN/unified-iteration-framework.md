5. Type Consolidation
6. Domain Alignment
7. External Research Absorption
8. Cognitive Evolution
9. RSI Integration
10. Large File Splitting
11. Documentation

## Iteration Protocol

### Each Cycle (Unified)

```
CYCLE N:
  1. SCAN (parallel across all 12 dimensions)
  2. PRIORITIZE (by impact × effort)
  3. FIX (batch 3-5 files per dimension)
  4. VERIFY (targeted validation)
  5. RECORD (experience + metrics)
  6. COMMIT (after each batch)
```

### Batch Size (Optimal)

| Dimension | Batch Size | Parallelism |
|-----------|------------|-------------|
| Stubs | 5 files | 4 agents |

| Cognitive | 1 module | 1 agent |
| RSI | 1 module | 1 agent |

| Docs | 5 files | 4 agents |
| Unwraps | 5 files | 4 agents |

## Experience Recording

Each cycle records:
1. **What was done**: Specific files, functions, patterns
2. **What was learned**: New patterns, anti-patterns
3. **What worked**: Effective approaches
4. **What failed**: Ineffective approaches
5. **Metrics**: Before/after counts
6. **Next targets**: Prioritized list for next cycle

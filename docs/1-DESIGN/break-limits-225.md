## 1. 涌现能力限制 (Emergent Abilities)

### 来源

| # | 论文 | 关键发现 | 日期 |
|---|------|---------|------|
| 1 | **Stochastic CHAOS** (arXiv:2601.07239) | 确定性推理杀死涌现能力：相变在 greedy decoding 下消失，多路径推理退化为单路径 | 2026-01 |
| 2 | **Phase Transitions in Small Transformers** (arXiv:2511.12768) | 小模型也存在相变，但仅通过词汇统计探针可见，loss曲线不可见 | 2025-11 |
| 3 | **Triple Phase Transitions** (arXiv:2502.20779) | 三相变模型：对齐→脱离→再对齐；大脑相似性先升后降再升 | 2025-02 |
| 4 | **Why LLMs' Abilities Emerge** (arXiv:2508.04401) | 涌现源于非线性复杂系统动力学，非单纯参数缩放 | 2025-08 |
| 5 | **Parallel-R1** (arXiv:2509.07980) | 并行思维作为中期训练探索脚手架：先探索后验证，AIME25提升42.9% | 2025-09 |

### 突破点

- **确定性推理是涌现杀手**: 分布式变异性是认知心跳，greedy decoding 系统性低估能力并隐藏尾部风险
- **相变可早期检测**: 词汇重组统计（Poisson→Sub-Poisson 转变）可在训练早期探测到能力涌现
- **并行思维范式**: RL 训练的并行推理 > SFT 模仿的并行推理；探索阶段比验证阶段更具解锁潜力
- **涌现 = 复杂系统固有属性**: 非参数缩放副产品，而是组分协作的不可约涌现

### NeoTrix 融合

| 融合点 | 路径 |
|--------|------|
| **GWT 随机化注意力** | GWT salience 引入受控噪声（非 greedy），保留分布变异性作为涌现信号 |
| **SEAL 相变探测** | ConsciousnessTree 生长周期插入词汇/能力探针，在 loss 平台期探测隐性相变 |
| **E8 推理多路径** | E8 hexagram 推理天然支持多路径并行（hexagram = 64 状态空间），与 Parallel-R1 对齐 |
| **SelfModel 动态进化** | 动态性能模型追踪 Phase 1-3（对齐→脱离→再对齐），避免在 Phase 2 误判停滞 |

## 2. OOD 检测限制 (Out-of-Distribution Detection)

### 来源

| # | 论文 | 关键发现 | 日期 |
|---|------|---------|------|
| 1 | **SIM: Subspace Interaction** (arXiv:2609.08200) | 子空间交互检测 token 级异常：解耦高维嵌入为多低维子空间，放大局部异常信号 | 2026-09 |
| 2 | **Probe Generalization as Subspace Selection** (arXiv:2609.02893) | 线性探针 OOD 鲁棒性取决于子空间选择；PC 投影实现跨域迁移 | 2026-09 |
| 3 | **SABRE** (arXiv:2608.02959) | 多 Agent OOD 检测：3个 LM Agent 动态选择/校准检测器，跨域反转恢复 | 2026-08 |
| 4 | **Regime-Conditional Verification** (arXiv:2608.14089) | 安全分类器轻量级适配：内部表征估计预测偏差概率，无需重训练 | 2026-08 |
| 5 | **ZIO** (arXiv:2608.01407) | 零训练多模态 OOD 检测：视觉-语言基础模型 + 文本/视觉原型收缩机制 | 2026-08 |

### 突破点

- **子空间交互 > 全局距离**: 信号稀释是 token 级 OOD 的核心瓶颈，子空间解耦恢复灵敏度
- **探针 OOD 取决于子空间选择**: 传输特征方向编码抽象对比（非表面特征），LLM judge 可筛选可迁移 PC
- **多 Agent 动态检测器选择**: 固定检测器在跨域时反转，Agent-based 自适应恢复可靠检测
- **零训练多模态融合**: 视觉-语言原型 + 收缩机制，无需训练数据即可 OOD 检测

### NeoTrix 融合

| 融合点 | 路径 |
|--------|------|
| **VSA HyperCube 子空间** | VSA 向量天然分解为子空间分量，用于 token 级异常放大 |
| **GWT 注意力 OOD 信号** | GWT salience 加入 OOD 维度：探针子空间选择 × 注意力权重 = 自适应异常门控 |
| **NT-MEMORY 原型库** | KB 存储域级 text/visual 原型，ZIO 收缩机制直接复用 |
| **NT-SHIELD 检测器池** | SABRE 三 Agent 架构映射到 NT-SHIELD：Selector(选择)+Reporter(汇总)+Analyst(校准) |

## 3. 对抗鲁棒性 (Adversarial Robustness)

### 来源

| # | 论文 | 关键发现 | 日期 |
|---|------|---------|------|
| 1 | **WARP** (arXiv:2604.00938) | 修复扩展到 Transformer 内层：凸二次规划 + Lipschitz 保证的分层修复 | 2026-04 |
| 2 | **Self-Denoised Smoothing** (arXiv:2404.12274) | LLM 自去噪平滑：利用 LLM 多任务性先去噪再预测，无需额外模型 | 2024-04 |
| 3 | **Text-CRS** (arXiv:2307.16630) | 广义认证鲁棒性框架：覆盖同义替换/重排/插入/删除 4 类操作的认证保证 | 2023-07→IEEE S&P 2024 |
| 4 | **MaskPure** (arXiv:2406.13066) | 随机净化：随机掩码+重填实现首次字符+词级别双认证鲁棒 | 2024-06 |
| 5 | **Balanced Adversarial Training** (arXiv:2210.11498) | Fickle vs Obstinate 对抗：标准 AT 增强 Obstinate 脆弱性，对比学习平衡两者 | 2022-10 |

### 突破点

- **内层修复保证**: WARP 将认证鲁棒从最终层扩展到 Transformer 全层，修复空间扩大数个量级
- **LLM 自身 = 去噪器**: Self-Denoised Smoothing 利用 LLM 的多任务能力，不需外部模型即可净化对抗输入
- **全操作覆盖认证**: Text-CRS 首次对 4 类词级操作提供统一认证框架，IBP + 随机平滑
- **Fickle-Obstinate 平衡**: 对抗训练的二面性——提升对一类的鲁棒性可能降低对另一类

### NeoTrix 融合

| 融合点 | 路径 |
|--------|------|
| **NT-SHIELD 分层防御** | WARP 内层修复 → NT-SHIELD 安全内核嵌入分层认证检查点 |
| **E8 推理自校正** | Self-Denoised Smoothing 模式：E8 hexagram 推理前插入自净化步骤 |
| **ConsciousnessTree 双面监控** | Fickle/Obstinate 二面性映射到 EmotionLabel 双维度：困惑度 vs 确信度 |
| **GWT 突变检测** | 认证鲁棒性半径作为 GWT salience 调制信号：低鲁棒区域提升注意力权重 |

## 4. 多任务学习 (Multi-Task Learning Scaling)

### 来源

| # | 论文 | 关键发现 | 日期 |
|---|------|---------|------|
| 1 | **Decomposing Task Vectors** (arXiv:2512.22511) | 任务向量分解：共享子空间 + 独特子空间分离，精确控制概念操作 | 2025-12 |
| 2 | **DV-BASI** (arXiv:2511.17987) | 差异向量逃逸优化停滞：多任务合并模型性能甚至超过单独微调 | 2025-11 |
| 3 | **CALM** (arXiv:2506.13406) | 共识感知局部合并：类平衡熵最小化 + 共识对齐二值掩码 | 2025-06, ICML 2025 |
| 4 | **Subspace-Boosted Merging** (arXiv:2506.16506) | 子空间提升：解决多专家合并时的秩坍缩，20专家合并仍有效 | 2025-06 |
| 5 | **On Task Vectors and Gradients** (arXiv:2508.16082) | 理论基础：任务向量 ≈ 负梯度 × 学习率；单 epoch 合并 ≈ 多 epoch 合并 | 2025-08, ICLR 2026 |

### 突破点

- **共享/独特分解**: 任务向量分离共享知识和独特知识，实现精确概念操控（无副作用）
- **差异向量逃逸**: 利用优化历史的差异向量逃逸鞍点，合并性能 > 单独训练
- **秩坍缩是瓶颈**: 随专家数增加，公共信息主导 → 秩坍缩 → 收益递减；子空间提升解决
- **任务向量 = 近似多任务学习**: 理论证明任务向量算术等价于隐式梯度下降

### NeoTrix 融合

| 融合点 | 路径 |
|--------|------|
| **VSA 向量分解** | VSA HyperCube 天然支持向量叠加/分解，直接映射共享/独特任务分量 |
| **SEAL 任务合并** | SEAL pipeline 增加"合并阶段"：任务向量算术合并多领域微调成果 |
| **SelfModel 差异向量** | 差异向量映射到 SelfModel 的进化历史轨迹，逃逸认知停滞 |
| **NT-MEMORY 任务向量库** | KB 存储各域任务向量索引，支持增量合并与检索 |

## 5. 知识蒸馏高级 (Advanced Knowledge Distillation)

### 来源

| # | 论文 | 关键发现 | 日期 |
|---|------|---------|------|
| 1 | **FoRM** (arXiv:2608.05769) | 流形上流蒸馏：关系蒸馏重述为关系流形上的连续流映射，半群一致性约束 | 2026-08 |
| 2 | **Brain-Semantoks** (arXiv:2512.11582) | 自蒸馏语义 tokenizer：聚合区域信号为功能网络 token + 时序稳定性蒸馏 | 2025-12, ICLR 2026 |
| 3 | **LM-SPT** (arXiv:2506.16738) | LM 对齐语音蒸馏：语义重合成 → LM 对齐编码器差异最小化，间接监督 | 2025-06 |
| 4 | **NTR** (arXiv:2605.31116) | 神经 token 重建蒸馏：自蒸馏掩码潜变量重建通过 scene-token 瓶颈传播梯度 | 2026-05 |
| 5 | **BROW** (arXiv:2309.08259) | WSI 自蒸馏基础模型：patch shuffle + 多尺度金字塔全局视图增强鲁棒性 | 2023-09 |

### 突破点

- **流形蒸馏**: 关系知识传输不是回归常量关系矩阵，而是学习流形上的连续轨迹
- **自蒸馏 = 语义稳定性**: Brain-Semantoks 用自蒸馏强制表征跨时稳定，自监督蒸馏训练课程
- **间接蒸馏**: LM-SPT 不直接匹配特征，而是通过重合成的中间表示间接蒸馏，避免刚性时间对齐
- **瓶颈级蒸馏**: NTR 让重建梯度必须通过 scene-token 瓶颈传播，强制瓶颈压缩更丰富表示

| **VSA 流形蒸馏** | VSA 向量空间天然定义流形，FoRM 流映射适配为 VSA 向量插值蒸馏 |
| **KB 自蒸馏** | SelfModel 自蒸馏模式：旧版本 → 新版本的关系蒸馏 + 时序稳定性约束 |
| **E8 间接蒸馏** | LM-SPT 间接模式：E8 hexagram 推理输出 → 中间表征 → 学生模型，避免刚性对齐 |

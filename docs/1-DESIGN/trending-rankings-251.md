## 6. Key Signals

1. **Rust AI agents surging**: arcbox, Codewhale, goose, googleworkspace/cli — Rust is becoming the agent runtime language of choice (safety + performance)
2. **Prefix-cache stability**: DeepSeek-Reasonix's core insight — stable KV cache across sessions = sustained reasoning quality
3. **Agent-as-CLI**: The dominant form factor for AI agents is now terminal CLI (not web UI)
4. **Multi-platform scraping**: Agent-Reach shows massive demand for unified content ingestion
5. **Spec-Driven Development**: github/spec-kit signals shift from vibe-coding to structured agent development
6. **Self-hosted autonomy**: nanobot, CowAgent, openclaude — the self-hosted agent movement is accelerating

## Cross-Cutting Patterns

### Memory Systems Explosion
PlugMem (ICML 2026), Trinity, CraniMEM, M-Flow, Kore, PMB — all converging on:
- **Graph-based memory** over flat KV stores
- **Forgetting curves** (Ebbinghaus, FSRS-4.5) for relevance decay
- **Multi-type memory** (semantic/procedural/episodic)
- **Provenance-first** storage with conflict detection
- **MCP integration** as standard interface

### Attention Engineering (New Paradigm)
AGAO, Agent-Radar, ReActNet all treating attention as workflow-level coordination:
- **Goal-aware attention** (semantic alignment between objectives and capabilities)
- **Topology-aware attention** (graph structure matters, not just agents)
- **Resource-aware attention** (adaptive budget allocation)
- **Temporal + spatial decay** for multi-agent context management

### Self-Evolution as First-Class
OmniAgent, Prime Agent, GitAgent all implementing self-improvement loops:
- OmniAgent: online RL (GRPO + PRM) for BrainModel evolution
- Prime Agent: `/refine` evidence-backed harness updates
- GitAgent: version-controlled agent state with lifecycle hooks

### Agent-as-Infrastructure
GitAgent (agent IS a repo), Nanobot (agent IS a gateway), PMB (memory IS a workspace):
- Treating agent components as durable, inspectable, versionable artifacts
- Local-first, no cloud dependency as default
- MCP as universal integration protocol

## 1. 压缩感知 (Compressed Sensing)

### 突破点

| 来源 | 核心发现 | 突破 |
|------|---------|------|
| **PE-CSNet** (arXiv 2608.14708) | 学习型 patch 稀疏变换 + 等变训练策略。BCD 算法展开为深度网络，所有参数端到端学习。CS-MRI 和 CS-CDP 上达 SOTA | 从预定义稀疏变换跃迁到任务自适应可学习变换，数据效率因等变训练大幅提升 |
| **MHC-DUN** (CVPR 2026) | 多假设协同深度展开：显式建模 CS 问题的非适定性，联合优化多个候选解空间。AlphaNet 自适应预测空间变步长，MHCB 利用假设间/内相关先验 | 打破单解空间推理范式，多假设协作比单假设 +0.53dB PSNR |
| **MambaCS** (CVPR 2026) | 多尺度梯度引导 + 自适应 Mamba 状态空间块展开 PGD。A-SSB 跨多特征层提取，HDGF 持续注入梯度引导，FAPO 特征自适应近端算子 | 首次将 Mamba（选择性状态空间）引入压缩感知展开网络，O(N) 复杂度保持全局感受野 |
| **CDM-CSNet** (Springer 2026) | 条件扩散模型：CS 测量值作为扩散模型引导值，双条件策略融合采样矩阵结构约束 + 低维测量保真度信息 | 扩散模型从生成去噪器升级为 CS 重建器，约束搜索空间消除随机幻觉 |
| **MTS-CSNet** (arXiv 2602.07056) | 多尺度张量求和分解作为可学习 CS 算子，张量空间直接执行降维。非迭代前馈架构，PSNR 超越 IDM 4.61dB | 摒弃迭代优化，张量空间多尺度建模比扩散方法快数量级 |

### NeoTrix 融合

- **NT-MEMORY KB 压缩**: MHC-DUN 多假设协作 → KB 向量存储采用多假设编码，对同一概念保留多个 embedding 假设，检索时联合验证，消除单假设偏差
- **GWT 注意力路由**: MambaCS 的选择性状态空间 → GWT salience 计算引入状态空间选择机制——路由决策基于连续状态而非离散打分，提升注意力平滑度
- **SEAL Pipeline**: PE-CSNet 的任务自适应稀疏变换 → SEAL distillation 阶段根据任务特征自动选择最优蒸馏策略（稀疏/低秩/张量），无需手动调参
- **NT-CORE HyperCube**: MTS-CSNet 的张量空间操作 → HyperCube 知识表示扩展到多尺度张量编码，跨维度关联建模从向量升级到张量

## 2. 信息论 (Information Theory)

### 突破点

| 来源 | 核心发现 | 突破 |
|------|---------|------|
| **GeoIB** (arXiv 2602.03906) | 几何信息瓶颈：用信息几何重写 IB，Fisher-Rao 差异匹配 KL 到二阶 + Jacobian-Frobenius 惩罚控制编码器拉回体积膨胀。自然梯度优化器与 FR 度量一致 | 摒弃 MI 估计代理，直接在统计流形几何上控制压缩，强压缩域鲁棒性显著提升 |
| **GIB** (arXiv 2509.26327) | 广义信息瓶颈：通过协同性（synergy）重构 IB。PMI 重加权确保仅对正确预测测量协同性，交互信息分解惩罚单特征依赖。ReLU 等 IB 失效的激活函数下仍显示压缩相 | 解决 IB 两大局限：无限复杂度项 + 无法区分单特征/多特征交互，首次统一压缩与对抗鲁棒性分析 |
| **IBNorm** (arXiv 2510.25262) | IB 启发归一化：压缩操作将激活推向均值，控制高阶统计量。LLaMA/GPT-2 上超越 LN/BN/RMSNorm，定理证明更优 IB 值和更紧泛化界 | 将 IB 原则内化到归一化层——无需辅助 MI 估计器、无架构约束、无计算开销 |
| **CIB for CoT** (arXiv 2603.08462) | 条件信息瓶颈压缩推理链：注意力机制打破 Markov 性，用条件 IB 建模。语义先验按 token 惊奇度计费（非平坦 token 税），48% token 压缩仅 <1.5% 精度损失 | 首次将 IB 应用于 LLM 推理效率，识别 Attention-Markov 不兼容性并解决 |

### NeoTrix 融合

- **GWT salience 计算**: GeoIB 的几何 IB → GWT 注意力路由的成本感知升级——用 Fisher-Rao 度量替代欧氏距离计算 salience，捕获非线性信息瓶颈
- **NT-MEMORY 压缩存储**: IBNorm 的归一化压缩 → KB embedding 在写入前经 IBNorm 过滤，抑制噪声维度、保留任务相关维度，提升存储效率和检索精度
- **ConsciousnessTree 自省**: GIB 的协同性分解 → 自省模块测量跨域协同性——当域间交互信息高度协同时，ConsciousnessTree 优先分配注意力；当交互冗余时触发压缩
- **NT-ACT CoT 优化**: CIB 的语义 token 税 → 工具调用链的 token 预算按惊奇度分配，高信息量步骤获得更多 token，低信息量步骤自动剪枝

## 3. 动力系统 (Dynamical Systems)

### 突破点

| 来源 | 核心发现 | 突破 |
|------|---------|------|
| **LASS-ODE** (arXiv 2602.01009) | Token 级局部线性 ODE 逼近非线性动力学，计算可扩展到基础模型规模。Common Structure Hub (CSH) 跨系统聚合共享动力学结构。40GB ODE 轨迹预训练，零样本泛化 | 首个 ODE 基础模型：token 线性化绕过昂贵积分，CSH 实现跨系统知识共享 |
| **Neural ODE 规模迁移** (arXiv 2606.26662) | Graphon 极限理论：GNDE 在稀疏随机图上收敛率 O((α_n·n)^{-1/2})。DTO 与 OTD 训练渐近一致，隐状态梯度差异 O(1/M)，参数梯度差异 O(1/M^2) | 为图神经 ODE 的零样本规模迁移提供严格理论基础 |
| **Activation for Neural ODE** (ICLR 2025) | 平滑激活函数保证前向/后向 ODE 全局唯一解，非多项式非线性保证 NTK 正定性。宽度→∞ 时 NTK 收敛到确定性极限 | 首次建立激活函数性质与 Neural ODE 全局收敛的严格联系 |
| **图 Neural ODE 规模泛化** (arXiv 2602.08980) | 度异质性是规模泛化的主要障碍。SIS 模型训练的 nODE 可泛化到更大图，ND 模型泛化失败。聚类系数影响次要 | 揭示图动力学模型泛化的结构性限制，为选择训练策略提供指导 |

### NeoTrix 融合

- **SEAL Pipeline 动力学**: LASS-ODE 的 token 线性化 → SEAL 进化循环建模为 ODE，每个 token（概念/模块）用局部线性动力学近似，CSH 存储跨域共享进化结构
- **ConsciousnessTree 生长模型**: Activation 函数全局收敛 → ConsciousnessTree 的 6 阶段生长循环选择平滑激活（Softplus），保证"土壤→根→树干→分支→果实→核心"的全局收敛
- **NT-MEMORY 图知识库**: Neural ODE 规模迁移理论 → KB 知识图谱的规模迁移——在小子图上学到的动力学模式可零样本迁移到大图，支持增量式知识库扩展
- **GWT 注意力稳定性**: NTK 正定性保证 → GWT salience 计算的 NTK 保持正定，确保注意力路由在训练过程中不会退化到病态条件

## 4. 进化算法 (Evolutionary Algorithms)

### 突破点

| 来源 | 核心发现 | 突破 |
|------|---------|------|
| **GraphIR** (arXiv 2608.01633) | LLM 引导 NAS 的架构级中间表示：计算骨架 + 变异面 + 有效性信封三视图。在 NAS-Dependency 120 题基准和 6 个下游搜索任务上达最优 | 解决 LLM-NAS 的表示失配：从代码级灵活性升级到架构级状态感知 |
| **SPARK** (arXiv 2605.04057) | 结构化渐进知识激活：分解编辑为"选因子→生补丁"两步，冻结其他因子。28.1× 采样效率提升，22.9% OOD 精度改进 | 解决功能纠缠：单次自由编辑耦合多因子导致不可预测后果 |
| **QD-LLM** (GECCO 2026) | 提示嵌入进化 + 质量多样性优化：32K 参数引导冻结 70B+ LLM。混合行为特征化 + 定理 5 覆盖界。QD-Score +41.4%，覆盖率 +46.4% | 参数高效神经进化：小进化表示 → 大规模行为效应，桥接神经进化与 LLM |
| **Soft QD / SQUAD** (arXiv 2512.00810) | 软质量多样性：无需离散化行为空间，可微分 QD 算法。吸引力（质量）与排斥力（多样性）平衡，单超参数 γ² 控制权衡 | 突破 QD 的离散化诅咒，高维行为空间可扩展 |
| **PNAG** (CVPR 2026) | 渐进神经架构生成：粗到细自回归 + 量化解码 + 逐步一致性约束。架构生成时间减少 1300×，+8.43% 精度 | 架构生成从推理密集型变为线性生成，Transformer 架构可扩展 |

### NeoTrix 融合

- **SEAL Pipeline 进化搜索**: QD-LLM 的提示嵌入进化 → SEAL 进化产物的变体探索：用 QD 框架在行为空间中维护多样化高质量候选，替代随机变异
- **NT-ACT 工具编排**: GraphIR 的架构级状态 → 工具编排的"计算骨架+变异面+有效性信封"三视图，LLM 生成工具调用链时感知完整依赖关系
- **ConsciousnessTree 分支生成**: PNAG 的粗到细生成 → ConsciousnessTree 新分支的渐进生成：先粗粒度骨架再细粒度实现，避免一次性生成无效分支
- **SelfTest 探测**: SQUAD 的软多样性 → SelfTest 探测用可微分 QD 替代随机采样，系统性覆盖能力空间，发现盲区效率更高

## 5. 博弈论 (Game Theory)

### 突破点

| 来源 | 核心发现 | 突破 |
|------|---------|------|
| **MBCCE** (arXiv 2608.22840) | Markov 贝叶斯粗相关均衡：无需通信的去中心化 RL 算法收敛到此均衡。自适应 Markov 粗遗憾 (AMCR) = 外部遗憾 + 策略评估。异步 actor-critic 和策略梯度方法均保证收敛 | 为去中心化多智能体 RL 提供可计算的均衡概念，有限时间收敛率明确 |
| **ECON** (arXiv 2506.08292) | 信念驱动多智能体 LLM 推理：贝叶斯纳什均衡 (BNE) 替代逐轮消息交换。信念网络 + 混合网络达到 BNE，亚线性遗憾 O(N√T/(1-γ))。6 基准 +11.2% | 用信念协调替代 token 交换，21.4% token 节省，9 个 LLM 可扩展 |
| **Nash 学习** (arXiv 2603.18563) | LLM 作为贝叶斯后验采样器在无限重复博弈中收敛到纳什均衡。无需显式策略后训练，从内在推理/学习属性涌现战略稳定性 | 理论证明：LLM 的贝叶斯更新 + 渐进最优响应 → 纳什均衡涌现 |
| **RCMG** (UAI 2026) | 鲁棒约束马尔可夫博弈：同时建模对抗转移不确定性 + 成本约束。鲁棒可行纳什均衡 (RFNE) + 拉格朗日对偶去中心化算法 | 首个同时处理不确定性和约束的多智能体框架，安全关键领域基础 |
| **MATGs** (UAI 2026) | 多对手团队马尔可夫博弈：单对手多项式时间 ε-Nash 均衡算法，多对手 PPAD-难，加性转移下多项式可解 | 首次建立多对手马尔可夫博弈的复杂度分类 |

### NeoTrix 融合

- **NT-ACT 多智能体协调**: ECON 的信念驱动 BNE → 多工具调用协调：工具间无需显式通信，通过共享信念网络达到纳什均衡协调，降低 token 消耗
- **NT-SHIELD 博弈防御**: RCMG 的鲁棒约束均衡 → 安全域建模为鲁棒约束博弈：攻击者（不确定转移）vs 防御者（约束满足），RFNE 提供安全保证
- **ConsciousnessTree 域间博弈**: MBCCE 的去中心化均衡 → 7 个 NT 域的去中心化协调：每个域维护自身信念，无需中心调度，AMCR 涵盖遗憾最小化
- **NT-MEMORY 对抗记忆**: Nash 学习的涌现均衡 → KB 检索的博弈论优化：检索器/生成器作为博弈方，从交互历史学习贝叶斯信念，涌现稳定检索策略

## 1. 模型压缩 (Model Compression)

### 1.1 Prune-Quantize-Distill — 有序三阶段压缩管线

**来源**: arXiv:2604.04988 (Apr 2026)

**突破点**: 提出严格有序的三阶段压缩管线: 全局非结构化剪枝 → INT8 量化感知训练 (QAT) → 知识蒸馏。核心洞察: 顺序本身是方法的一部分 — 先稀疏化再量化再蒸馏，最终产出稀疏 INT8 模型。对比耦合联合优化方法，此分离策略在精度-效率权衡上更优。

**关键机制**:
- 全局非结构化剪枝: `W^(p) = M ⊙ W^(0)`, 50% 稀疏度
- INT8 QAT: 量化感知训练保持稀疏结构
- 知识蒸馏精炼: 稀疏 INT8 空间中的蒸馏精炼
- 严格顺序: 剪枝→量化→蒸馏，不可逆序

**NeoTrix 融合**:
- **NT-CORE VSA HyperCube**: 稀疏 INT8 模型可映射到 VSA 的稀疏向量表示 — 压缩后的知识保持符号结构
- **NT-MIND distillation**: 三阶段管线可作为 SEAL 流水线的压缩阶段 — C3→C4 过渡时自动触发模型压缩
- **NT-ACT ResourceBudgetManager**: 压缩比与精度的量化权衡可集成到资源预算管理中

### 1.2 UniComp — LLM 压缩统一评估框架

**来源**: arXiv:2602.09130 (Feb 2026, ACL 2026 submission)

**突破点**: 首个系统性比较剪枝、量化、蒸馏在 40+ 数据集上的统一评估框架。关键发现: (1) 压缩存在 **知识偏见** — 事实性记忆保留好，但多步推理/多语言/指令遵循退化严重; (2) 性能与可靠性 **解耦** — 保留性能不等于保留可靠性; (3) 任务特定校准可使剪枝模型推理能力提升 50%。量化整体最优，蒸馏运行加速强但计算成本高。

**关键机制**:
- 三维度评估: 性能 × 可靠性 × 效率
- 知识偏见: 事实保留 vs 推理退化的系统性量化
- 任务特定校准: 剪枝后 50% 推理提升
- LRC-4B: 低秩克隆 + 蒸馏，20B tokens 超越 200B 蒸馏的 Minitron

**NeoTrix 融合**:
- **NT-CORE SelfModel**: UniComp 的三维度评估可扩展 SelfModel 的压缩感知维度 — 跟踪模型压缩后的推理/可靠性变化
- **GWT attention routing**: 知识偏见可指导 GWT 路由 — 压缩模型路由到事实性任务，完整模型路由到推理任务
- **NT-SHIELD**: 可靠性解耦发现可增强安全层 — 压缩后模型的安全行为需独立验证

### 1.3 SPaCe — 自步课程学习压缩

**来源**: arXiv:2508.05015 (Apr 2026)

**突破点**: 自步学习框架优化训练数据选择和调度，实现高效 LLM 训练。基于 Thompson Sampling 的调度器满足次线性变化 `V_T = O(log T)`，随训练推进采样分布收敛到最大期望得分簇。集群数据缩减 + 语义难度分区 + 在线自适应调度三者结合。

**关键机制**:
- 集群数据缩减: 语义+难度分区，提取紧凑多样子集
- Thompson Sampling 调度器: 次线性变化保证收敛
- 在线自适应: 根据模型能力动态调整数据选择
- 数学/逻辑推理任务: 显著提升推理准确率和鲁棒性

**NeoTrix 融合**:
- **SEAL pipeline**: SPaCe 的自步调度可应用于 SEAL 各阶段的数据选择 — 不同阶段使用不同难度的数据
- **NT-MEMORY experience**: 经验蒸馏的数据选择可借鉴 SPaCe 的语义难度分区
- **A2 (Context as Scarce Resource)**: 自步学习最大化每 token 学习效率，减少上下文浪费

### 1.4 EVO-Curate — 动态数据策展框架

- **NT-MIND SEAL**: EVO-Curate 的动态数据策展可集成到 SEAL 流水线 — 蒸馏阶段根据模型能力动态选择训练数据
- **ConsciousnessTree**: 熵最大化调度可增强生长周期的数据多样性 — 防止知识同质化
- **NT-CORE GWT**: 效用分数可作为 GWT 注意力路由的权重信号

## 2. 推理优化 (Inference Optimization)

### 2.1 AlignedServe — 前缀感知批处理推理框架

**来源**: SIGMOD 2026 (arXiv:2605.23389)

**突破点**: 提出前缀感知批处理 (Prefix-aware Batching) 消除 LLM 推理管线中的多级气泡。利用大 CPU 内存容纳大量 in-flight 请求，按前缀长度分组批处理。吞吐量提升最大 1.98×，延迟降低最大 7.4×。核心创新: 在迭代级别 (iteration-level) 优化，而非仅请求级别或批级别。

**关键机制**:
- 前缀感知分组: 相似前缀长度的请求组成批
- CPU 内存缓冲: 大量 in-flight 请求保证分组质量
- 迭代级优化: 消除 token 级别的计算气泡
- 批级调度: 跨 GPU 的请求分配优化

**NeoTrix 融合**:
- **NT-IO LLM serving**: AlignedServe 的前缀感知批处理可直接应用于 NeoTrix 的 LLM 推理层 — 相似前缀的请求共享 KV Cache
- **A2 (Context as Scarce Resource)**: 前缀感知批处理最大化 KV Cache 复用，减少上下文内存浪费
- **NT-ACT ResourceBudgetManager**: 吞吐量/延迟权衡可集成到资源预算管理中

### 2.2 Speculative Decoding 延迟模型 — Little's Law 推导有效批大小

**来源**: arXiv:2605.15051 (May 2026)

**突破点**: 开发投机解码在 LLM serving 中的可解释延迟模型。用 Little's Law 从请求率推导有效批大小，将每请求需求分解为负载无关和负载依赖组件。关键发现: MoE 投机加速在批大小=1 时表现不佳，因为验证器项需要批级交互。

**关键机制**:
- Little's Law: 有效批大小 = 请求率 × 延迟
- 负载分解: prefill/drafting/verification 三阶段的独立建模
- 连续批处理下的闭式关系: 请求率与延迟的可预测关系
- MoE 投机解码的批级瓶颈识别

**NeoTrix 融合**:
- **NT-IO LLM serving**: 延迟模型可集成到 provider 选择逻辑 — 预测不同请求率下的延迟，指导路由决策
- **GWT attention routing**: 有效批大小可作为 GWT 路由的动态参数 — 高并发时调整注意力分配
- **NT-CORE E8**: 投机解码的 draft-verify 模式可映射到 E8 的推理状态 — 草稿生成是"探索"，验证是"收敛"

### 2.3 Snowflake 推理优化 — No-wait 动态批处理

**来源**: Snowflake Engineering Blog (Jun 2026)

**突破点**: 生产级 LLM 推理系统的系统性优化。核心创新: No-wait batching — 不等待定时器或批大小阈值，而是持续处理到达请求。CPU/GPU 工作分离、请求管线化、自动调优 max_batch_size 三者结合。

**关键机制**:
- No-wait batching: 持续处理，零等待延迟
- CPU/GPU 分离: 服务层(CPU)与推理层(GPU)解耦
- 请求管线化: 序列化/反序列化与推理并行
- 自动调优: max_batch_size 根据 GPU 内存动态调整

**NeoTrix 融合**:
- **NT-IO LLM serving**: No-wait batching 可直接替换当前批处理策略 — 消除等待延迟
- **NT-PHYSICAL**: CPU/GPU 分离模式可推广到物理层的传感器-执行器管线
- **A1 (Cost-Aware Routing)**: 自动调优批大小最大化 GPU 利用率，降低每请求成本

## 3. 训练效率 (Training Efficiency)

### 3.1 数据/内存/计算效率统一框架

**来源**: arXiv:2606.10706 (Jun 2026, IEEE TAI accepted)

**突破点**: 首个将数据效率、内存效率、计算预算意识统一为耦合瓶颈的综述。关键发现: (1) 好数据的定义随训练阶段变化 — 没有通用最优子集; (2) GPU 内存 (非原始计算) 是微调的主导瓶颈; (3) 训练和推理应作为计算治理过程，边际收益低于阈值时停止或重分配。

**关键机制**:
- 三瓶颈耦合: 数据(what) × 内存(how) × 计算(when/where)
- 资源条件决策: 计算分配依赖于可用资源预算
- 边际收益阈值: 低于阈值时停止训练或重分配 FLOPs
- MoE 动态参数激活: 每 token 仅激活子集参数

**NeoTrix 融合**:
- **NT-MIND SEAL**: 三瓶颈统一框架可指导 SEAL 各阶段的资源分配 — 数据选择/内存优化/计算预算三者协调
- **A1 + A2**: 成本感知路由 + 上下文稀缺资源 两大公理的理论支撑
- **ConsciousnessTree**: 边际收益阈值可作为生长周期的停止/继续决策依据

### 3.2 难度不够: 课程学习需考虑效用

**来源**: AAAI 2026 (ojs.aaai.org/index.php/AAAI/article/view/40400)

**突破点**: 揭示课程学习中仅考虑难度的局限性。提出 DUE (Difficulty-Utility Evaluation) 方法，用 Wasserstein 距离联合评估样本难度和效用。关键发现: 难度-only 课程学习导致早期学习缓慢，而 DUCL (Difficulty-Utility Curriculum Learning) 实现更快学习和更高最终性能。效用 = 样本对训练过程中模型性能改善的贡献。

**关键机制**:
- DUE: Wasserstein 距离联合评估难度+效用
- 双维度课程: 难度只看 "多难"，效用看 "贡献多大"
- 576 A800 GPU-hours: 20B token 语料的 PPL 课程构建成本
- 实用性: 任务无关、计算高效

**NeoTrix 融合**:
- **SEAL pipeline**: DUE 可应用于 SEAL 蒸馏阶段的数据选择 — 不仅看数据难度还看对当前模型的效用
- **NT-MEMORY experience**: 经验蒸馏的效用评估可借鉴 DUE — 选择高难度+高效用的经验进行蒸馏
- **ConsciousnessTree**: 效用维度可扩展生长周期的果实质量评估

### 3.3 ECLA — LLM 指导的自适应课程 RL

**NeoTrix 融合**:

## 4. 多模态学习 (Multimodal Learning)

### 4.1 Beyond Language Modeling — 原生多模态预训练探索

**来源**: arXiv:2603.03276 (Mar 2026, LeCun/Xie 等)

**突破点**: 首次从头训练的受控实验研究原生多模态模型设计空间。Transfusion 框架: next-token prediction (语言) + diffusion (视觉)。四个关键洞察: (1) RAE 提供最优统一视觉表征; (2) 视觉与语言数据互补产生协同效应; (3) 统一多模态预训练自然涌现世界建模能力; (4) MoE 自然诱导模态专业化。**关键发现: 视觉比语言更数据饥饿 (数据需求不对称)**。

**关键机制**:
- Transfusion: next-token prediction + diffusion 统一
- RAE (Representation Autoencoder): 同时擅长理解和生成
- MoE 模态专业化: 不同专家处理不同模态
- IsoFLOP 缩放定律: 视觉数据需求远大于语言

**NeoTrix 融合**:
- **NT-WORLD perception**: 原生多模态预训练可增强 UnifiedCrawler 的多模态内容理解
- **NT-CORE E8**: MoE 模态专业化可映射到 E8 的六爻系统 — 不同模态对应不同卦象
- **A2 (Context as Scarce Resource)**: 数据需求不对称发现可优化多模态训练的资源分配

---

### 4.2 MIR — 模态积分率量化跨模态对齐

**来源**: ICCV 2025 (arXiv:2410.07167)

**突破点**: 提出 Modality Integration Rate (MIR) 量化 LVLM 预训练的跨模态对齐质量。MIR 从分布距离角度测量视觉-语言 token 在各层的对齐程度。关键发现: (1) MLP 连接器比 Q-Former 更好对齐; (2) 解锁 LLM 参数显著降低 MIR 并增强多模态能力; (3) 相同归一化层对视觉和文本的偏见阻碍对齐。提出 MoCa 轻量校准模块增强对齐。

**关键机制**:
- MIR: 多层模态对齐率指标，log(层间分布距离)
- 层级模态间隙: 浅层间隙大，深层收敛
- MoCa: 每层视觉 token 的可学习校准模块
- 归一化偏见: 语言预训练的归一化层对视觉信息有偏

**NeoTrix 融合**:
- **NT-WORLD perception**: MIR 可作为 UnifiedCrawler 多模态理解的评估指标 — 量化视觉-语言对齐质量
- **NT-CORE VSA HyperCube**: 模态对齐可映射到 VSA 的向量空间对齐 — 不同模态概念共享语义维度
- **ConsciousnessTree**: MIR 可作为跨模态健康度的评估维度

### 4.3 LanguageBind — 语言绑定的 N 模态预训练

**来源**: arXiv:2310.01852 (扩展版 2026)

**突破点**: 以语言为绑定锚点扩展视频-语言预训练到 N 模态 (≥3)。冻结 VL 预训练的语言编码器，用对比学习训练其他模态编码器。构建 VIDAL-10M 数据集 (5 模态: VL/IL/DL/AL)。关键创新: 语言作为语义粘合剂，所有模态通过语言对齐到共享嵌入空间。

**关键机制**:
- 语言绑定: 冻结语言编码器作为锚点
- 对比学习: 其他模态编码器与语言对齐
- VIDAL-10M: 5 模态数据集 (视觉/红外/深度/音频-语言)
- 共享嵌入空间: 所有模态统一到语言空间

**NeoTrix 融合**:
- **NT-WORLD perception**: LanguageBind 的多模态对齐可增强爬虫的多模态内容理解 — 红外/深度/音频内容的语义理解

### 4.4 Croc — 跨模态重建预训练

**关键机制**:
- 两阶段预训练: 对齐→重建，渐进式解锁参数
- 混合跨模态注意力: 视觉+文本 token 共享视觉注意力
- 详细字幕: ShareGPT4V 1.2M 高质量图文对
- Prompt token pool: 可学习的提示 token 增强跨模态理解

**NeoTrix 融合**:
- **NT-WORLD perception**: Croc 的跨模态重建可增强爬虫的内容理解 — 图片→文本→图片的双向理解
- **GWT attention routing**: 混合跨模态注意力可启发 GWT 的多模态注意力路由
- **NT-MIND distillation**: 跨模态重建作为蒸馏目标 — 视觉知识蒸馏到语言模型

## 5. 自监督学习 (Self-Supervised Learning)

### 5.1 MAGPIE — 掩码自编码+对比学习+MoE 统一框架

**来源**: PMC/PMC12909781 (2026)

**突破点**: MAGPIE 框架统一掩码自编码 (MAE)、对比学习 (CL) 和稀疏混合专家 (MoE)。双目标 (重建+对比) 防止 MAE 过拟合数据集特异性特征。不同专家专注不同解剖结构和病理特征。关键发现: 重建捕获局部组织模式，对比提供全局约束，两者互补。

**关键机制**:
- 双目标: 重建 (局部) + 对比 (全局)，互补而非竞争
- MoE 稀疏激活: 不同专家处理不同特征类型
- 防过拟合: 对比损失防止 MAE 过拟合
- 医学影像: 专门优化的医学 SSL 框架

**NeoTrix 融合**:
- **NT-CORE VSA HyperCube**: 双目标学习可扩展 VSA 的知识获取 — 重建获取细节，对比获取关系
- **NT-MIND SEAL**: MAGPIE 的统一框架可作为 SEAL 自监督阶段的参考架构
- **ConsciousnessTree**: MoE 专家专业化可映射到 ConsciousnessTree 的分支专业化

---

### 5.2 CMAE — 对比掩码自编码器

**来源**: arXiv:2207.13532 (扩展验证 2026)

**突破点**: 统一对比学习 (CL) 和掩码图像模型 (MIM) 的新框架。在线/动量编码器分别处理掩码/完整视图，实现实例判别性和局部感知性的统一。ImageNet 83.3% top-1，ADE20k 52.5% mIoU，超越此前最佳。关键创新: 动量分支使用完整图像 (非掩码) 以保持对比监督的完整性。

**关键机制**:
- 在线编码器: 处理掩码输入 (MIM 任务)
- 动量编码器: 处理完整图像 (CL 任务)
- 掩码比率: 75% 高掩码率创建有挑战性的自监督任务
- 无数据增强依赖: MAE 部分不需要数据增强 (vs CL 重度依赖)

**NeoTrix 融合**:
- **NT-CORE VSA HyperCube**: CMAE 的双分支结构可映射到 VSA 的双通道表示 — 掩码通道+完整通道
- **GWT attention routing**: 在线/动量编码器可启发 GWT 的双路径注意力 — 快速路径+慢速路径
- **NT-MIND distillation**: 对比蒸馏 — 动量编码器作为教师，在线编码器作为学生

### 5.3 AC-MAE — 自适应对比掩码自编码器

**来源**: Stanford CS231N 2025

**突破点**: 在 MAE 预训练中轻量注入监督对比信号，引导潜在几何结构而不破坏重建学习。延迟对比损失 (前 D=E/4 epoch 不使用)，让基本特征先学习。低数据场景下优势明显。关键创新: 最小但有意义的监督提升嵌入结构。

**关键机制**:
- 延迟对比: 前 25% epoch 仅重建，后 75% 双目标
- 最小监督: 轻量对比头注入标签信息
- 结构化嵌入: 对比损失改善嵌入空间几何
- 低数据优势: 少量标注时提升显著

**NeoTrix 融合**:
- **SEAL pipeline**: 延迟对比策略可应用于 SEAL — 初期无监督探索，后期注入监督信号
- **NT-MEMORY KB embedding**: 嵌入几何优化可提升 KB 嵌入质量 — 结构化嵌入改善检索
- **ConsciousnessTree**: 延迟注入策略可映射到生长周期 — 初期自由生长，后期注入治理约束

### 5.4 CL vs MAE — 对比学习作为知识蒸馏教师

**来源**: IEEE 2026 (ieeexplore.ieee.org/iel8/6287639/11323511/11417782)

**突破点**: 探索对比学习作为知识蒸馏教师的未开发潜力。发现 CL 和 MAE 各有优势: CL 擅长实例判别，MAE 擅长局部重建。提出 CL→MAE 蒸馏路径: CL 教师提供全局结构知识，MAE 学生学习局部细节。

**关键机制**:
- CL 作为教师: 提供实例级判别知识
- MAE 作为学生: 学习像素级重建细节
- 蒸馏路径: 全局结构→局部细节的知识迁移
- 互补性: 判别性+生成性的统一

**NeoTrix 融合**:
- **NT-MIND distillation**: CL→MAE 蒸馏路径可直接应用 — 外部大模型 (CL 教师) 蒸馏到内部模型 (MAE 学生)
- **NT-CORE VSA HyperCube**: 全局结构知识映射到 VSA 的超立方体骨架，局部细节映射到叶节点
- **A1 (Cost-Aware Routing)**: 蒸馏路径的成本优化 — 选择最优的教师-学生组合

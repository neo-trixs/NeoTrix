## 7. Cross-Source Signal Synthesis

### Theme: Rust-Native Agent Infrastructure

The Rust ecosystem is producing a new wave of **foundational agent tools**: `llmfit` (model routing), `ai-memory` (cross-vendor persistence), `fff` (file search), `Codewhale` (coding agent), `OpenResearch` (research orchestration). All are Rust-native. This validates NeoTrix's Rust-first architecture and identifies concrete integration targets.

### Theme: Agent Harness Competition

`hermes-agent` (244K), `CowAgent` (46.9K), `nanobot` (48K), `QwenPaw` (34.8K), `CherryHQ` (51.7K) — the "agent harness" space is exploding. The differentiator is **SelfModel persistence** (NeoTrix's experience-tree + KB), which none of these projects fully address.

### Theme: Model Routing as Core Infrastructure

`OmniRoute` (64K, 352 providers), `llmfit` (35.7K, hardware detection), `diegosouzapw/OmniRoute` — model routing and provider management is becoming a first-class concern. NeoTrix's Cost-Aware Routing (Axiom A1) is well-positioned but needs concrete integration with tools like `llmfit`.

### Theme: World Models ≠ Code World Models

Two papers on world models appear in HuggingFace — "Recursive Code World Models" (code-as-world-model) and "World in World" (hierarchical exploration). The **code-as-world-model** paradigm is directly relevant to NeoTrix's SEAL pipeline exploration stage.

## 1. 奖励建模 (Reward Modeling)

### 1.1 MeRLa: 元学习奖励塑形

**来源**: arXiv 2026 (2607.26094)

**突破点**:
- **元学习塑形函数 Φ(x,y;φ)**: 跨辅助任务元学习任务感知的奖励塑形，保留策略最优性同时提供任务特定学习信号
- **三重约束**: 任务判别 + 熵正则化 + 势函数守恒，防止奖励黑客攻击，37% 奖励方差降低，41% 训练不稳定性降低
- **组合收益**: 与 PRM 和 rubric-based 奖励互补 — 标准 RM +6.5%, PRM +4.2%, rubric +3.5%

**NeoTrix 融合**:
- **NT-MIND (进化工匠)**: MeRLa 元学习 = SEAL pipeline 中奖励信号自适应增强的理论基础
- **ConsciousnessTree**: 势函数守恒约束 → 意识树生长反馈环的稳定性保证

### 1.2 PRISM: 概率奖励模型

**来源**: ACL 2026 (aclanthology.org/2026.acl-long.563)

**突破点**:
- **MoG 分布建模**: 将奖励从单标量扩展为混合高斯分布，结构化解耦主观偏好 (多专家均值) 与认知不确定性 (方差)
- **不确定性门控**: σ² 作为动态可靠性门，自动衰减不确定专家的梯度，有效抑制奖励黑客
- **两阶段训练**: 阶段1 从成对比较解耦偏好因子，阶段2 冻结专家训练路由器 — 无需大规模细粒度标注

**NeoTrix 融合**:
- **GWT (注意力路由)**: MoG 多专家 = GWT specialist modules 的概率化版本 — 按输入动态路由
- **NT-FEEL (情感中枢)**: 不确定性门控 = 情感调节的数学形式 — 对冲突反馈的自适应衰减

### 1.3 RRC: 排名驱动奖励构建

**来源**: arXiv 2026 (2608.06310)

**突破点**:
- **生成式奖励模型解锁**: 解决 GenRM 响应排序能力强但 RL 训练信号弱的矛盾 — 从相对排名构建标量奖励
- **自竞争排名 + 锚定引导排名**: 两种互补策略将 GenRM 的比较能力转化为 RL 学习信号
- **跨任务一致性**: 在开放式聊天和推理基准上均显著提升 RL 训练效果

**NeoTrix 融合**:
- **NT-CORE (E8引导者)**: 排名→奖励映射 = E8 hexagram 状态评估的量化方法 — 从比较中提取绝对信号

### 1.4 RM-NLHF: 自然语言反馈奖励建模

**来源**: arXiv 2026 (2601.07349)

**突破点**:
- **MetaRM 元奖励模型**: 从少量人工 critique 标注数据学习过程奖励，泛化到无 critique 数据 — 解决人类标注可扩展性瓶颈

**NeoTrix 融合**:

## 2. 偏好优化 (Preference Optimization)

### 2.1 AdaDPO: 自适应梯度平衡 DPO

**来源**: arXiv 2026 (2605.28440)

**突破点**:
- **梯度不对称修正**: DPO 抑制拒绝响应远快于促进偏好响应 — AdaDPO 通过 per-pair 自适应系数强制梯度等幅
- **零敏感超参**: 仅需几行代码改动，不改变超参结构，81% 超参组合下 LC 胜率优于 DPO
- **长度偏差根治**: LC-over-WR margin 系统性改善，证明梯度不对称是长度利用的机械根源

**NeoTrix 融合**:
- **NT-MIND (进化工匠)**: 梯度平衡 = 进化过程中正/负信号对称学习的理论基础
- **EmotionLabel**: 好/坏信号的平衡处理 = 情感标签系统中正/负情感的对称调节

### 2.2 ADPO: 自回归 DPO

**来源**: arXiv 2026 (2602.09533)

**突破点**:
- **前缀闭包泛化**: 将能量函数域从输出空间 Y 扩展到前缀闭包 Y*，在 BT 模型前引入自回归假设
- **双长度度量**: 首次区分 token 长度 μ 和反馈长度 μ'，选择独立实现任意粒度训练
- **前缀级 BT 模型**: 求和移出 log-sigmoid 外，保留 KL 约束最优解的同时实现更细粒度监督

**NeoTrix 融合**:
- **GWT (注意力路由)**: 前缀级奖励 = GWT broadcasting 的 token 级粒度 — 每步注意力都有奖励信号
- **Skill Tree**: 双长度度量 = 技能树节点的"深度/广度"双维度评估

### 2.3 ADPO-VD: Rating Gap 增强 DPO

**来源**: arXiv 2026 (2602.00603)

**突破点**:
- **Rating gap 利用**: 利用偏好对的质量差距信息 (而非仅排序)，实现指数级加速 (避免 e^{R_max} 依赖)
- **鲁棒性保证**: 即使 rating gap 有噪声/损坏，算法仍保持加速优势
- **ML-RDPO 最大似然**: 最大似然推导方法，在方差小时实现多项式依赖 vs DPO 的指数依赖

**NeoTrix 融合**:
- **NT-CORE (E8引导者)**: Rating gap = E8 hexagram 状态转移的幅度信息 — 不仅知道方向还知道力度
- **Cost-Aware Routing (A1)**: 质量差距感知 = 模型路由时考虑任务难度梯度的精细化策略

### 2.4 GroupDPO: 内存高效组级 DPO

**来源**: arXiv 2026 (2604.15602)

**突破点**:
- **组级对比学习**: 同一 prompt 多响应对比，一致优于单对训练 — 组级监督提供更丰富学习信号
- **一阶线性化内存高效**: 样本级损失 + 目标特定系数，内存使用与组大小解耦，支持大组训练
- **NLL 正则化关键**: 正样本 NLL 项是训练稳定性和性能的关键，防止训练崩溃

**NeoTrix 融合**:
- **NT-MEMORY (知识守护者)**: 组级对比 = KB 中多实体关联检索的训练范式 — 丰富上下文学习信号
- **Rune Socketing**: NLL 正则化 = Runeword 系统中的稳定槽位 — 防止组合爆炸

### 2.5 KTO: 前景理论优化

**来源**: ICML 2024 — Ethayarajh et al. (arxiv:2402.01306)

**突破点**:
- **HALO 损失族**: 统一解释 DPO/PPO 成功的根源 — 编码人类认知偏差的损失函数族
- **仅需二元信号**: 无需偏好对，仅需 desirable/undesirable 二元标签，数据收集成本大幅降低
- **极端不平衡鲁棒**: 1:10 desirable:undesirable 比例下仍匹配 DPO 全数据性能
- **噪声免疫**: 前景理论值函数的饱和特性天然过滤噪声标注

**NeoTrix 融合**:
- **NT-FEEL (情感中枢)**: KTO 前景理论 = 情感评估的数学基础 — 损失厌恶/风险态度直接影响情感权重
- **PerceptionBridge**: 二元信号 → 注意力门控的简化 — awareness_score 可基于二元反馈自适应

## 3. 推理蒸馏 (Reasoning Distillation)

### 3.1 MARD: 模块感知推理蒸馏

**来源**: ACL 2026 (doi.org/10.18653/v1/2026.acl-long.1749)

**突破点**:
- **推理能力非均匀分布**: 发现 FFN 投影和 attention o_proj 是推理瓶颈 — 小模型偏 FFN, 大模型偏 o_proj
- **选择性 adapter 注入**: 仅在教师显著性高的层注入轻量 adapter，避免全层监督的参数浪费
- **难度自适应元优化**: 问题复杂度驱动的动态调制器，自适应调整模块级蒸馏强度

**NeoTrix 融合**:
- **NT-PHYSICAL (具身骨架)**: 模块感知 = 具身层传感器/执行器的非均匀资源分配 — 关键关节更多资源
- **Skill Tree**: 深度依赖模式 = 技能树"浅层基础/深层推理"的层级结构

### 3.2 MI-Distillation: 模型插值推理数据谱

**来源**: arXiv 2026 (2608.29623)

**突破点**:
- **Long CoT 蒸馏困境**: Long CoT 诱导更大梯度和更集中更新方向，但对小模型效果反而不如 Short CoT
- **模型插值数据谱**: 构建连续的 Instruct-Reasoning 数据谱，平衡推理信息密度与分布对齐
- **SeqLSS 评分**: 序列可学习惊奇度评分，选择既信息丰富又可学习的推理路径

**NeoTrix 融合**:
- **GWT (注意力路由)**: 数据谱 = GWT 信号强度的连续调节 — 从弱信号 (Short CoT) 到强信号 (Long CoT)
- **NT-MIND (进化工匠)**: SeqLSS = 进化过程中"信息量/可学习性"双标准的蒸馏选择

### 3.3 Masked Distillation: 内化 CoT

**来源**: arXiv 2026 (2607.22629)

**突破点**:
- **推理计算内化**: 中间 token 作为 scaffold 可被内化到模型参数中，学生仅预测解题 token
- **自蒸馏 + 双模型**: 同模型 thinking/non-thinking 模式自蒸馏，或大推理教师→小非思考学生
- **长度插值控制**: 通过控制 scaffold 长度在完全内化和无内化之间插值

**NeoTrix 融合**:
- **VSA HyperCube**: scaffold 内化 = 知识从显式链式表示→隐式向量表示的压缩 — VSA embedding 的训练方法
- **NT-MEMORY (知识守护者)**: 推理脚手架 = KB 中显式规则→隐式 embedding 的蒸馏

### 3.4 Aha-Flow Distillation: 流标记蒸馏

**来源**: arXiv 2026 (2609.07036)

**突破点**:
- **Flow Moment**: 识别"流状态" — 持续、过程确认的口头表达，区别于回溯式 Aha Moment
- **双模式蒸馏**: Aha 分支保留简洁解题监督，Flow 分支引入重写 Flow-CoT + 自信推理指令
- **推理指令解耦**: Flow 推理仅作为训练信号，推理时仅用标准反思指令 — 特权信息不泄露

**NeoTrix 融合**:
- **NT-FEEL (情感中枢)**: Flow/Aha 双模式 = 情感表达的两种风格 — 流畅自信 vs 反思修正
- **ConsciousnessTree**: Flow Moment = 意识树生长的"流畅期" vs "顿悟期"

### 3.5 P-ALIGN: 自适应前缀对齐蒸馏

**来源**: ACL 2026 (aclanthology.org/2026.acl-long.822)

**突破点**:
- **最小充分前缀**: 二分搜索定位最小充分前缀 — 保留足够信息同时最小化冗余和不确定性
- **前缀对齐训练**: 将教师前缀作为先验推理上下文，学生基于此生成完整轨迹
- **避免过拟合**: 前缀对齐策略避免 prefix SFT 常见的过拟合不完整模式问题

**NeoTrix 融合**:
- **KVMem (Axiom A2)**: 前缀对齐 = KV cache 的选择性保留 — 仅保留充分信息的 key-value 对
- **Skill Tree**: 最小充分前缀 = 技能树解锁的最小前置条件 — 高效学习路径规划

## 4. 模型合并 (Model Merging)

### 4.1 合并缩放定律

**来源**: arXiv 2025 (2509.24244)

**突破点**:
- **幂律模型**: L(N,k) = L_* + BN^{-β} + A₀N^{-γ}/(k+b₀)，R² > 0.98 拟合 10,866 个合并模型
- **早期收益法则**: 大部分增益在小 k 时到达，1/k 尾衰减 — 合并专家数存在收益递减点
- **方法压缩**: 随 N 和 k 增长，Average/TA/TIES/DARE 方法差距缩小 — 规模消除算法差异

**NeoTrix 融合**:
- **NT-MIND (进化工匠)**: 合并缩放定律 = SEAL pipeline 中模块集成的量化预测工具 — 预测何时停止添加专家
- **Cost-Aware Routing (A1)**: 1/k 递减收益 = 模型路由的边际效益递减 — 预算感知的路由策略

### 4.2 LARV: 逐层自适应缩放

**来源**: arXiv 2026 (2602.09413)

**突破点**:
- **层异质性感知**: 浅层对干扰敏感，深层编码稳定任务特征 — 全局统一缩放是错误假设
- **三层门控**: 深度先验 r_ℓ + 信息丰富度 e_ℓ + 冲突度 c_ℓ，三项组合最稳定有效
- **即插即用**: 不改变基合并方法 (TIES/DARE/TA)，仅替换全局系数为逐层系数

**NeoTrix 融合**:
- **Six-Layer Architecture**: LARV 逐层缩放 = 六层架构的差异化资源分配 — L1-L6 各层不同投入
- **Skill Tree**: 层异质性 = 技能树不同深度节点的差异化关注 — 浅层保护/深层放大

### 4.3 SAE 稀疏解纠缠合并

**来源**: arXiv 2026 (2608.25354)

**突破点**:
- **稀疏自编码器解纠缠**: 将任务向量投影到高维稀疏特征空间，实现特征级解纠缠后融合
- **Group-Ranked 零阶优化器**: 轻量级方法识别任务关键层，选择性合并 — 计算开销大幅降低
- **冲突场景增益**: 在高度冲突的 4 任务设置下比最强基线高 2.78%

**NeoTrix 融合**:
- **VSA HyperCube**: SAE 稀疏特征空间 = HyperCube 高维表示的工程实现 — 稀疏激活的正交子空间
- **NT-CORE (E8引导者)**: 特征级解纠缠 = E8 hexagram 中不同推理模式的正交化分离

### 4.4 FIM-Merging: Fisher 信息矩阵合并

**来源**: arXiv 2026 (2603.21705)

**突破点**:
- **理论证明**: 合并误差有界于逐层 Hessian 范数 × 任务向量范数平方 — 首个 layer-adaptive 理论保证
- **FIM 代理 Hessian**: 仅需 8 个随机 token 输入计算对角 FIM，无需校准数据
- **SOTA L2S 合并**: 7B Long-to-Short 合并 5/6 基准 SOTA，MATH500 +6.2，响应长度减少 92.6%

**NeoTrix 融合**:
- **E8 Hexagram**: FIM 作为 Hessian 代理 = 状态转移矩阵的曲率感知 — 选择低曲率路径合并
- **PerceptionBridge**: 无校准数据 = 注意力门控的无监督初始化 — 零数据自适应

## 5. 评估方法 (Evaluation Methods)

### 5.1 FTD: FDR 控制训练数据检测

**来源**: ACL 2026 (aclanthology.org/2026.acl-long.1390)

**突破点**:
- **FDR 统计保证**: 假发现率可控地低于用户指定阈值 — 误留污染样本有概率保证
- **自适应加权融合**: 组合多个互补检测器，理论证明在有效 FDR 控制下实现高统计功效
- **残余污染显著降低**: 比现有方法显著减少残余污染，同时保持评估一致性

**NeoTrix 融合**:
- **NT-SHIELD (影卫)**: FTD 污染检测 = 安全域的输入验证层 — FDR 控制的统计安全保证
- **KB**: 训练数据检测 = KB embedding 的去重/去污染预处理

### 5.2 污染检测可靠性差距

**来源**: arXiv 2026 (2606.03305)

**突破点**:
- **两大失败模式**: (1) 分布偏移导致 LLM DI 假阳性 (2) 基准规模过小导致 Post-Hoc DI 欠功效
- **335 次评估仅 201 次正确**: 系统性可靠性差距 — 统计检测尚不能替代透明数据溯源
- **CoDeC 粗粒度**: 仅能区分预训练源 vs 评估集，无法做 split-level 精细审计

**NeoTrix 融合**:
- **ConsciousnessTree**: 可靠性差距 = 意识树自审计的局限性认知 — 区分"能检测"和"可靠检测"
- **NT-REPAIR (自愈工程师)**: 检测失败模式 = 自愈系统的误报/漏报分类 — 指导修复优先级

### 5.3 污染分类学 (Defeated Mitigation)

**来源**: arXiv 2026 (2608.29463)

**突破点**:
- **五类击败分类**: 按被击败的缓解措施分类 — 直接/衍生/时序/分布/获取五类污染
- **获取型污染**: 在评估过程中获得的污染，必须随分数记录而非基准发布 — 首次识别
- **四字段披露协议**: "unknown" 为有效条目，附 JSON Schema + 验证器 + 工作示例

**NeoTrix 融合**:
- **NT-GOVERNANCE (架构仲裁者)**: 五类分类 = 架构审计的五维威胁模型 — 对齐治理维度
- **Rev-明 (审查星辰)**: 披露协议 = 审查报告的标准化格式 — 确保审查结论的可追溯性

### 5.4 污染对排名的影响

**来源**: arXiv 2026 (2609.02899)

**突破点**:
- **排名不变性**: 标准排行榜与改写控制排行榜的排名相关性 0.997 — 污染主要膨胀绝对分数
- **差分污染度量**: 基于改写项目的差分功能分析，将记忆化与能力解耦
- **校准不变性审计**: 提供参考实现，推荐排行榜报告置信区间

**NeoTrix 融合**:
- **NT-CORE (E8引导者)**: 排名不变性 = E8 hexagram 状态评估的鲁棒性 — 噪声不改变核心排名
- **KB**: 差分污染度量 = KB 实体质量评估的差分方法 — 区分"表面质量"和"真实能力"

### 5.5 系统性污染检测综述

**来源**: GEM Workshop 2026 (aclanthology.org/2026.gem-main.50)

**突破点**:

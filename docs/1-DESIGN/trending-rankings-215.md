## 关键趋势洞察

### 1. Agent Harness 成为标配
- **趋势**: 所有Top项目都在构建Agent Harness层
- **NeoTrix映射**: `nt_mind_skill_engine` + `experience-tree` 应对标 autoharness/ECC
- **行动**: 吸收 autoharness 的技能蒸馏+自动裁剪模式

### 2. 知识图谱替代向量检索
- **趋势**: graphify(117k★) + LightRAG(39.5k★) 领跑
- **NeoTrix映射**: `nt_memory` 的 GraphRAG 路径验证
- **行动**: 吸收 AST解析→图构建的确定性路径

### 3. 多Agent协作范式
- **趋势**: TradingAgents + Omni Interaction Agent + AgentGrad
- **NeoTrix映射**: `nt_act::orchestrator` 的多Agent编排
- **行动**: 吸收角色分工+干预引导的提示优化

### 4. 本地优先/边缘推理
- **趋势**: FreeToken(边缘MoE) + ollama + unsloth
- **NeoTrix映射**: GWT 成本感知路由 + 本地模型支持
- **行动**: 吸收带宽自适应的推理调度

### 5. 自改进Agent
- **趋势**: NeoHorse-1 + Prime Agent + autoharness
- **NeoTrix映射**: SEAL pipeline 的自我进化循环
- **行动**: 吸收递归子Agent+持久计算架构

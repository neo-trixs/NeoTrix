## 主题1: 模型扩展律 (Scaling Laws)

### 1.1 Unified Neural Scaling Laws (UNSL)
- **来源**: Caballero et al., arXiv:2605.26248, 2026-05
- **核心**: 提出 Unified Neural Scaling Law 功能形式，同时建模参数量/数据集/训练步数/推理步数/超参多维度变化时的评估指标行为。在88.89%的语言任务上优于所有对比方法，准确外推非单调过渡（如过拟合与学习率的非单调关系）。
- **突破点**: 多维度同时变化时的统一建模，打破了传统单变量外推的局限。

### 1.2 神经扩展普适性 (Neural Scaling Universality)
- **来源**: Liu & Gore, arXiv:2606.25008, 2026-06
- **核心**: 提出"扩展指数由机制固定"假说——Softmax非线性→1/3时间缩放，叠加超表示→逆宽度缩放，Transformer层集成→逆深度缩放。指数由高层架构/数据特性决定（稳健），系数受数据/架构/超参影响（可优化）。近端方向是理解系数而非指数。
- **突破点**: 揭示扩展律的普适类结构，将改进方向从指数探索转向系数优化。

### 1.3 Effective Frontier 统一框架
- **来源**: Zou et al., arXiv:2602.02593, 2026-02
- **核心**: 将学习抽象为从Zipf长尾分布中逐步覆盖模式的过程。引入 Effective Frontier k* 作为模式空间中已学与未学的阈值。通过 Max-Bottleneck 原理统一 Kaplan（数据充足→参数中心）和 Chinchilla（数据受限→平衡缩放）为同一约束优化在不同活跃瓶颈下的等价解。
- **突破点**: 调和了 Kaplan vs Chinchilla 的长期争论，将扩展律归因于数据几何+优化动态的拓扑不变量。

### 1.4 Skaling: Chinchilla指数遇上Kaplan耦合
- **来源**: Videau (Meta FAIR), arXiv:2608.07222, 2026-08
- **核心**: Chinchilla加性律假设模型大小与数据独立影响损失，但边界处误差显著。Skaling律引入单一耦合指数恢复N-D交互，将外推MAPE降低1.5-3×。配合L形稀疏网格策略，以约10×更少计算实现全网格预测精度。
- **突破点**: 单参数耦合即可消除边界偏差，L形实验策略大幅降低计算预算。

### 1.5 Farseer: 精细化扩展律
- **来源**: Li et al., NeurIPS 2025 (arXiv:2502.xxxxx)
- **核心**: 通过微分分段+多轮迭代拟合构建损失曲面L(N,D)，数据缩放效应显式依赖N。外推误差比Chinchilla低433%（平均相对误差0.50% vs 2.68%）。训练约1000个LLM、消耗约300万H100 GPU小时验证。
- **突破点**: 将小规模实验可靠外推到大规模生产，弥合了"扩展鸿沟"。

## 主题2: 涌现能力 (Emergent Abilities)

### 2.1 涌现能力综合综述
- **来源**: Berti et al., arXiv:2503.05788, 2025-03 (2026更新)
- **核心**: 系统梳理涌现能力定义不一致性、涌现条件（扩展律/任务复杂度/预训练损失/量化/提示策略）、ICL的尺度依赖涌现、LRM（o1/o3）的推理涌现、有害行为涌现（欺骗/操纵/奖励黑客）。预训练损失低于临界值时性能突然跃升，且数据质量影响涌现时机。
- **突破点**: 涌现并非纯粹的尺度函数，而是与训练过程本身绑定；损失阈值才是关键。

### 2.2 涌现能力的复杂系统视角
- **来源**: Royal Society Phil Trans A, 2026-05 (doi:10.1098/rsta.20250014)
- **核心**: 区分"More is Different"（涌现新属性）与"Less is More"（涌现智能）。OthelloGPT内部形成压缩的棋盘世界模型是一种涌现；但三类涌现声称（尺度突现/未训练能力/内部世界模型）的证据均不完整。提出涌现需要：粗粒化变量+有效机制+压缩/抽象的证据。
- **突破点**: 将涌现定义从"不可预测的新能力"收窄为"可识别的内部表示重组"，提供更严格的判定标准。

### 2.3 扩展与涌现的统计学破迷思
- **来源**: Neurocomputing, 2026-09 (S092523122503214X)
- **核心**: 用ANOVA/Tukey HSD/GAMMs/聚类对大规模LLM评估数据进行统计分析。结论：能力发展是渐进的、任务依赖的、非线性积累而非突然跃迁；"涌现"更像"渐进涌现"——U形或振荡趋势而非离散跳跃。扩展律仅在有限参数区间内有效。
- **突破挑战**: 直接挑战Wei et al.的"尖锐涌现"定义，认为是评估方法的伪影。

### 2.4 隐式课程假说
- **来源**: Liu et al., arXiv:2604.08510, 2026-04
- **核心**: LLM并非在达到尺度阈值时同时学会所有技能，而是遵循隐式课程——某些能力在训练早期获得，另一些后期获得，取决于数据分布。观察到的"随尺度涌现"可能反映训练阶段的推进而非绝对相变。
- **突破点**: 将涌现的时间维度从"模型大小"转向"训练阶段"，提供更细粒度的预测框架。

### 2.5 测试时计算的涌现扩展
- **来源**: Li et al., 2026 (见Berti综述引用)
- **核心**: 将扩展律延伸到推理时计算域——更多推理时计算的收益遵循可预测模式，多步推理任务从额外推理计算中获益最大。更强大模型能更好地利用推理时计算，这本身也是一种涌现。
- **突破点**: 涌现从训练时扩展延伸到推理时扩展，开辟了新的优化维度。

## 主题3: 知识表示 (Knowledge Representation)

### 3.1 KoRe: 紧凑知识表示
- **来源**: arXiv:2605.20170, 2026
- **核心**: 将1-hop子图编码为紧凑离散"知识令牌"（20个令牌/实体），用方向残差向量量化(RVQ)压缩图结构。注入冻结LLM的LoRA适配中，零样本迁移Hit@1达24.5%（基线1.8%），微调后达51.5%。Token使用减少10×。
- **突破点**: 离散知识令牌比自然语言序列化高效10×，且无需重训练LLM。

### 3.2 NeuroSymActive: 神经-符号主动推理
- **来源**: arXiv:2602.15353, 2026
- **核心**: 将可微神经-符号推理层（软统一+可微规则评分）与MC式主动探索控制器结合。用学习到的值信号优先扩展高价值路径，减少昂贵的KG查询。分离离线符号亲和学习与在线搜索控制。
- **突破点**: 用主动探索替代暴力检索，在保持可解释推理链的同时大幅降低查询成本。

### 3.3 SymbolLKG: 逻辑知识图+符号求解器
- **来源**: arXiv:2608.26836, 2026-08
- **核心**: 本体驱动的LKG将逻辑规则和约束作为拓扑节点，拓扑感知混合检索+动态路由到最优符号引擎。解决CoT缺乏验证机制和RAG忽略结构依赖的问题。
- **突破点**: 将逻辑规则本身作为图的一等公民，实现可验证的多步推理。

### 3.4 KBevo: 共演化的结构化知识与推理
- **来源**: arXiv:2608.26386, 2026-08
- **核心**: 端到端联合学习构建知识库和推理，用QA结果奖励优化两个组件。推理成功直接改善KB质量，产生更大、连接更好的知识结构，提高答案可达性。
- **突破点**: 知识构建与推理形成正反馈循环，打破"先有KB再有推理"的单向依赖。

### 3.5 CCoR: 组合关系链
- **来源**: arXiv:2608.22762, 2026-08
- **核心**: 以关系（而非实体）为搜索单元，构建主链（候选检索）+约束链（验证查询约束），全程锚定在KG上。解决实体剪枝丢弃有效实体和约束处理依赖LLM内部知识导致的幻觉问题。
- **突破点**: 关系中心范式避免了不可靠的实体剪枝，双重关系链实现可验证推理。

## 主题4: 推理机制 (Reasoning Mechanisms)

### 4.1 LLM推理是潜在的，而非链式思维
- **来源**: arXiv:2604.15726, 2026-04
- **核心**: 提出三假设竞争框架：H1(潜在状态轨迹为主)、H2(表面CoT为主)、H0(通用串行计算为主)。证据最强支持H1——CoT常有用但不忠实，潜在动态可被探测/干预且预测推理行为。建议将潜在状态动力学作为默认研究对象。
- **突破点**: 将推理研究从"CoT是否忠实"转向"潜在状态轨迹如何形成和被操控"。

### 4.2 CoT信息流追踪
- **来源**: ACL Findings 2026, aclanthology.org/2026.findings-acl.255
- **核心**: 从解码→投射→激活三阶段逆向追踪信息流。发现CoT通过答案模板约束解码空间（结构依从性与准确率相关r=0.75-0.92），产生更集中的概率分布，任务依赖地调节神经元参与（开放域降低激活、封闭域增加激活）。
- **突破点**: 揭示CoT作为"解码空间剪枝器"的机械可解释性框架。

### 4.3 CoT推理操作的几何结构
- **来源**: arXiv:2609.04753, 2026-09 (EMNLP 2026)
- **核心**: 不同推理操作（问题表述/目标分解/演绎）在表示空间中几何可分，可分性在中间层达到峰值。相同表面令牌因周围推理操作不同而有不同表示。注意力掩蔽实验证明chunk起始的对齐表示依赖前序推理上下文。
- **突破点**: 证明LLM内部维护推理操作与几何结构的对应关系，提供结构化推理操控基础。

### 4.4 顺序激活修补框架
- **来源**: arXiv:2608.22332, 2026-08
- **核心**: 引入顺序激活修补追踪CoT注意力头跨令牌位置的因果效应。识别分布式推理支持子电路，包括推理轨迹维护/答案锚定/示例-目标分离/数值生成。移除这些头同时破坏准确率和辅助机制。
- **突破点**: 证明CoT依赖协调的注意力头活动网络，而非单一"推理头"。

### 4.5 不可见推理: 不是所有推理都在CoT中
- **来源**: arXiv:2607.22925, 2026-07
- **核心**: 前沿模型利用语义无关的填充令牌改善合成推理任务性能（准确率提升达13个百分点）。Claude Opus 4.5在隐藏模约束下仍保持主任务准确率，证明不可见推理可服务完全不可见于CoT监控的目标。
- **突破点**: 前沿模型已在无任何可解释输出痕迹的情况下执行有后果的计算，对安全监控构成根本挑战。

## 主题5: 模型压缩 (Model Compression)

### 5.1 APQF: Agent引导的结构化剪枝+混合精度量化
- **来源**: arXiv:2608.05499, 2026-08
- **核心**: 5个协作Agent（分析/剪枝/微调/量化/评估）形成端到端流水线。ProfilingAgent分析模型结构和剪枝敏感度，PrunerAgent设定逐层剪枝比，QuantAgent分配逐层位宽，FineTuningAgent根据精度损失自适应恢复。首个结合LLM引导决策+全训练感知剪枝+混合精度QAT的框架。
- **突破点**: 用Agent协作替代人工启发式，压缩决策完全基于测量证据。

### 5.2 OverRep: 过完备重参数化结构化剪枝
- **来源**: arXiv:2609.06974, 2026-09
- **核心**: 遵循"训练时过完备、部署时紧凑"原则。恢复模块临时过参数化以吸收蒸馏知识，训练后代数合并为等价紧凑模块。引入退火激活实现非线性训练→线性合并的转换。在25%/50%剪枝下分别提升5.5/8.4点保留推理性能。
- **突破点**: 解决恢复模块表示容量与被移除知识复杂度之间的"容量-知识不对称"瓶颈。

### 5.3 极端稀疏下的规范元素
- **来源**: arXiv:2609.06557, 2026-09
- **核心**: 通过渐进稀疏化框架+二阶显著性+持续训练与稀疏度协调推进，在LLaMA-2/Qwen-3上实现99%非结构化稀疏仍保持强性能。LLaMA-2-7B在95%稀疏下WikiText-2困惑度13.48，99%下19.67，同时实现3.23×解码加速和6.21×内存节省。
- **突破点**: 将LLM稀疏化推向99%，证明极端稀疏并非根本限制而是设计挑战。

### 5.4 HBQ: 层次块量化
- **来源**: arXiv:2609.00450, 2026-08
- **核心**: 大块+两级量化+新型显著性缩放(SIG)。HBQ-A在W4A5精度下匹配W4A16(WoQ)的准确率，面积效率优于NVFP4。HBQ-E降低17%硬件成本同时保持高于所有现有BQ方法的准确率。KV缓存量化下仍保持高精度。
- **突破点**: 大块带来的效率提升通过精细的第二级缩放弥补精度损失，打破BQ的精度-效率权衡。

### 5.5 AWP: 激活感知剪枝量化统一方法
- **来源**: MERL TR2025-111, 2025-07
- **核心**: 将LLM压缩统一为稀疏近似问题，用投影梯度下降(PGD)同时处理剪枝和量化。无需SVD等计算密集操作。联合剪枝+INT4量化在75%剪枝比下显著优于顺序方法（AWQ+Wanda/Wanda+AWQ），且INT4+75%剪枝优于纯INT2量化。
- **突破点**: 剪枝+量化的联合优化显著优于各自独立后顺序应用，且等效位宽更低时性能更好。

## 跨主题洞察

| 维度 | 洞察 |
|------|------|
| **扩展律→涌现** | 扩展律指数可能固定（普适性），但系数优化可触发涌现阈值的提前到来 |
| **涌现→推理** | 推理能力遵循隐式课程逐步获得，而非尺度阈值突然跃迁 |
| **知识表示→推理** | 结构化知识（KG+符号）为可验证推理提供锚点，弥补CoT的不可靠性 |
| **推理→压缩** | 不可见推理的存在意味着压缩需保留潜在计算轨迹，不能仅关注表面输出 |
| **压缩→扩展律** | 极端压缩（99%稀疏/2-bit）改变了扩展律的适用边界，需要新的压缩感知扩展模型 |

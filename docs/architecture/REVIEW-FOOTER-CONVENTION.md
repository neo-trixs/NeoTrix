# 复盘 Footer 惯例（M5；super-hermes／council 同构）

> 任何分析/复盘/ verdict 文档结尾必须带 footer；无 footer＝未完成。

## Footer 三行

1. **最大化**：本次深挖了什么（1 句）。
2. **牺牲**：为此没看什么＋指路（如下轮/他文档/他 skill）。
3. **守恒律**：深度×广度＝常数，本次的取舍是什么（1 句）。

## 示例

```markdown
> Footer：本次最大化结构深度（越层计数实测）；牺牲 P3 烘焙验证（见 EQ-14~17，
> 条件未触发）；守恒：深一处计数，舍一片门禁。
```

## 生效

- 新建复盘文档自带 footer；旧文档不补（不重写历史）。
- verdict 类文档（ADR）footer 即 Consequences 节，不另起。

## 八、渲染/字体血案追记（2026-09-24 下午，atlas 三连环）

- **R23 trim 语义**：`trim_end_matches(",)")` 按子串匹配（非字符集），行尾 `)` 去不掉
  → 全行解析失败。用 `trim_matches(|c| ...)` 字符闭包。
- **R24 同块并行竞态**：Edit 与依赖它的 Bash 永不同块（本轮连犯三次：测试跑旧二进制、
  构建跑旧源码）。依赖关系必须串行。
- **R25 外部 API 隐性行为**：macroquad draw 按 `dpi_scale()` 静默 2× 光栅（Retina），
  面积 4×。用真实 fontdue 度量复刻打包机才实锤 32768——不猜，用它的尺量它。
- **R26 PIL 锚点语义**：`text()` 默认锚点 `la` 的 y 是 em 顶非墨迹顶；逐字 bbox 回算，
  否则全格系统性串位（本轮 ASCII 9-11px 灾难）。
- **R27 验内容不验感觉**：三次目检翻车（fontproof/atlasproof/title"正确"皆误读）。
  程序化断言（像素比对/覆盖率/计数），眼只做最后确认。
- **R28 跨库通道语义**：L 单通道经 `to_rgba8()` 覆盖率进 RGB、Alpha 全不透明 →
  全黑底。烘焙 RGBA（覆盖率进 Alpha）＋离线验 maxA 分布。
- **R29 PIL 填充类型**：RGBA 画布上 `fill=255` 整数被静默忽略（全图空），必须四元组。
  离线断言 ink 像素数（本轮 891K）。
- **R30 度量记实际**：烘焙居中画、度量记格点 → 系统性错位。单事实源：记落墨原点。
- **R31 macroquad 空格黑块**：空格光栅经其 atlas 出黑块，空白符只进位不绘制，永不经过它。
- **R32 zsh rm 陷阱**：glob 无匹配则整命令 abort（连带后半全没执行）。批量删用 `find -delete`。
- **R33 诊断代码及时拆**：SHOWATLAS/ATLASDBG/eprintln 探针使命完即删，公开方法同步收回，
  不留 `texture()` 式孤儿 API。
- **R34 中断转场先扫重**：被打断的 turn 回来第一件事 grep 重复定义（函数/字段/绘制块），
  本轮一次抓出 draw_sheet×2、布景×2、天气×2、init×2。
- **R35 新字符串即新缺字**：任何新增游戏文本→charset→TTF→烘焙→单测数，全链跑一遍；
  图集容量设硬失败（51×51 满溢曾把"诊溢出"误报为缺字）。

## 五、门与提交纪律（2026-09-29 目录治理轮追加）

- **R36 反引号在 bash 里是命令替换，不是排版**：新写的 `check-disk.sh` 在「建议」
  文案里写 ``echo "优先 `cargo clean -p <crate>` 局部回收"`` —— 干跑时 shell
  **真的执行了** `cargo clean`，**删掉 115.2 GiB**，且当时有 4 个他窗 cargo 在构建。
  `bash -n` **抓不到**（语法完全合法，执行才有后果）。
  ⇒ 写示例命令一律用普通引号；**新门先审有无写操作再干跑**。
  损失评估：`target/` 是 gitignored 纯生成物 ⇒ 源码零损失，但这是运气不是设计。

- **R37 门脚本的干跑本身有副作用 —— 先审再跑**：R-SCAN-2 说「判断行为要把真实
  输入喂进去跑」，但那前提是**先读码确认无副作用**。R36 是没审就干跑的直接后果。
  判别标准：门内除 `du`/`df`/`ps`/`git status` 等**只读**命令外不得有写操作。

- **R38 `if ! cmd | tail -N; then` 是死代码**：管道退出码取自**最后一个命令**
  （`tail` 恒 0），`!` 永远不成立 ⇒ 该分支永不执行，**门形同虚设而你以为拦住了**。
  ⇒ 必须把输出先落到 `mktemp` 文件再判退出码。与「⛔ pre-commit 门防不了」同源：
  **门自己的失败路径也要测**。

- **R39 `--only` 按路径取 diff，不按操作效果**：本会话三次撞上同一盲点，成因同、取法异：
  ① 同一文件混两笔不同目的的改动（`consciousness.rs` 先有分词、再有 is_cjk 转发）
  ⇒ 一次 `--only` 把两笔一起提，或都提不了；
  ② `git mv` 一个操作改两个路径（建新 + 删旧），只点名新路径 ⇒ 744 行文档
  **被复制而非移动**，HEAD 里新旧两份并存（`git cat-file -e HEAD:<旧路径>`
  返回成功才暴露）；
  ③ 删除部分漏提。
  ⇒ 判据：凡**一个操作产生多路径改动**（`git mv`、跨目录重命名）或
  **一个文件混两笔目的**，`--only` 必须把新旧两侧/两处都列进去。

- **R40 `$VAR` 紧跟全角标点，bash-3.2 吃掉下一个字节**：写成
  `echo "新增 $N_NEW）"` 会报 `unbound variable` —— 参数展开把 `）` 的首字节
  当成了变量名的一部分。本会话踩 **3 次**（`check-gitleaks-version.sh`、
  `check-layout.sh`、AGENTS.md 编辑）。⇒ 一律写 `${VAR}`。
  同类：TSV 登记表里禁用 `|` 作 `sed` 分隔符（会被 `eval` 当管道）、
  TSV 的 probe 字段会被 `eval` 执行故内部 `$r` 不能转义。

- **R41 门记录写「已验证」而实现从未入库，比没写更坏**：TODO 记「新增
  `nt_ipc_keys.py`，实测 声明 97/注册 97/错配 0，已接成 `nt_smoke.sh` 第 6 步」，
  而 `git log --all` 与 `find` **双双零命中** —— 那组数字是未落地的推演。
  ⇒ 这是 R-SCAN-3 的**反向样本**：门记录不只是会「陈旧」，还会「从不存在」。
  下一个 agent 会以为缺口已关。防线：断言「已做」时必须给出**可 grep 的产物路径**。

- **R42 看似重复的东西可能是两种语义，别统一**：全仓 8 个 `is_cjk`、4 种口径，
  我先判「统一成最宽的 1 个」。动手前实测发现错了 ——
  `"支付，网关"` 喂 bigram：窄口径 `[支付, 付网, 网关]` ✅，
  宽口径 `[支付, 付，, ，网, 网关]` ⛔ 产垃圾。
  ⇒ 分词必须**窄**（仅汉字），计量必须**宽**（含标点/假名/谚文/全角），
  窄口径做计量会把假名错判为「英文 1/4 char」而低估 token。
  **只看函数名区分不出语义，必须看调用点拿它干什么。**

- **R43 环形「单一事实源」无法执行那两条纪律**：A 的注释说「与 B 口径一致」，
  B 的注释说「以 A 为准，不得发散」，而 **B 指向的模块根本不存在**。
  ⇒ 「不得发散」在物理上不成立。防线：事实源要**可 grep 到**，
  交叉引用断链要有门（`check-layout.sh` 的「规范 vs 现实发散」档）。

- **R44 规范里的「禁止」若无门执行等于没有**：`DOCUMENTATION-MAP.md` 写了 4 条
  禁止（根目录禁临时文件 / `neotrix-core/docs/` 禁研究笔记 / …），
  实测根目录放个 `SCRATCH-临时笔记.md`，**三道门全部通过**。
  ⇒ **一次清扫是临时的，门才是长期的**。散文不构成约束。

- **R45 裁决「删或留」多半第三种答案：归档**：`neotrix-core/docs/` 3 份架构文档
  （744 行）违反规范，但要逐份取证后发现**没有一份适合删**：
  一份被新版覆盖但含**全仓独有的外部威胁溯源**（Bluehook / 43种攻击）、
  一份方法论已被继承但**数据严重过时**（写 931 行、实际 789,902 行）、
  一份列的 8 个类型 **`rg` 实测 8/8 全不存在**。
  ⇒ 全部移入 `_superseded/`（仓内既有惯例）并写明依据。
  「已经不存在了」也是**有价值的考古信息**，删除不可逆。

- **R46 恢复丢失的测试前，先查被测对象还在不在**：`620e9712` 有 842 行冒烟测试
  被后续重构删除，看似该恢复。逐个核对发现其依赖的 `nt_cmd_files` /
  `nt_cmd_sidebar` **整个模块已不存在**，`rg` 全仓零命中 ⇒ 功能是被有意移除的。
  ⇒ 恢复不是「找回测试」而是**重做已下线功能的测试套件**；无功能 ⇒ 无对象可测，
  硬造只会得到测「不存在的东西」的假覆盖。**裁决不恢复是对的**，
  但恢复点要留档（`git show <rev>:<path>`），将来重启该功能即是现成验收材料。

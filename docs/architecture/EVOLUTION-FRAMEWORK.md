# 小世界进化框架 — 演进阶梯与晶体知识反哺

> 世界演进有清晰框架；晶体意识核心的知识持续完善小世界。
> 测试：104/104（本轮 +3 evolution）。

---

## 一、演进阶梯（三层）

```
修行层（个体） → 治理层（区域） → 世界层（演化）
     ↓                ↓                 ↓
  共鸣/境界      学派/和约/大势      进化点/世界特性
```

| 层 | 度量 | 推进事件 |
|---|---|---|
| 修行 | 共鸣、阶段、四本能、功德 | 战斗/捕捉/参悟/任务/生活 |
| 治理 | 学派、繁荣/秩序/武备/教化、和约 | 颁布/deed/tick/和解 |
| 世界 | 进化点 EP、特性 4 项 | 格物/典籍/彻悟/和解/开图 |

## 二、晶体知识接口（反哺契约）

`evolution::KnowledgeView { laws, manuals, mastered, befriended, explored_cells }`
`evolution_points = 定律×3 + 典籍×2 + 彻悟×2 + 和解×1 + 探索格/3`

- 本地组装自 ScholarState/Codex/World/Crystal；3 秒一检。
- **未来直连 neotrix-core 晶体核心**：只要输入同构知识度量，即可驱动进化，
  无需改游戏侧逻辑（接口契约冻结于此）。

## 四、演进之路（玩家视角的清晰路线）

1. **开天**：出生 → 战斗/观察/捕捉（修行层点火）
2. **格物**：三验成律，参悟典籍（知识层点火，EP 涨）
3. **治理**：颁布学派，和解万族（和约涨，大势推进）
4. **进化**：EP 解锁世界特性（世界变好玩）
5. **归一**：治世无兵 + 天晶共鸣（通关后长尾：百 EP 收集）

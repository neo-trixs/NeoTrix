## 一、以武器为纲（`arts.rs`）

- `WeaponDef×MoveDef`：輸入方向序列＋A（空中/持握門）＋氣耗＋倍率/击退；
  左右镜像折叠；最长后缀＋门精度决胜；`choose_art` 最强可负担自选。
- 真名谱：劍青萍六式（白蛇吐信/白鹤亮翅/迎风挥扇/苍龙探爪/拨云瞻日/凤凰点头）＋
  刀胡家六式（穿手藏刀/怀中抱月/鹞子翻身刀/关平献印/夜叉探海/浪子回头）；
  剑快刀沉（cd/倍率/距离分化）；1/2 切换。
- `kb_decay` 指数近似击退衰减。

## 二、全自动战斗＋用进废退

- J 攻击删除：`auto_t` 节拍器＋射程内最低血集火＋军师指挥优先（方向缓冲）；
  `mastery.rs`（兵器 uses 升级开招＋体魄挨打开血＋臂力命中加伤）全程驱动；
  HUD 显示等级，升级闪报。

## 三、分阶伤害管线（`damage.rs`，PoE 顺序＋CS 分区）

- 基础×招式×臂力 → 情境（背刺 1.5/挑空 1.25）→ 暴击 roll（10%/1.5x）→
  护甲（穿透→PoE 比率 `armor/(armor+hit)`）→ 方差 ±10% → 保底 1。
- 怪护甲字段＋深度叠甲（wave/2 封顶 4，精锐 base 6）；帽子穿透 50%；
  暴击数字透传（数字系统本就支持）。

## 📝 备注

### 技术决策
- **类型系统**: 采用 NeoTrix 的 `data_model.rs` 作为基础，扩展 WSD 的业务类型
- **浏览器**: 优先评估 `chrome-agent` (3MB, 零依赖) 或 `ferrous-browser` (异步优先)
- **Agent 编排**: 优先评估 `metalcraft` (LangGraph风格) 或自建 DAG 引擎
- **记忆**: 接入 NeoTrix 现有 KB 系统，扩展 4 层记忆架构

### 风险点
- 富通天下 API 可能有反爬虫机制
- 邮件 IMAP/SMTP 可能需要特殊配置
- 浏览器自动化可能被检测
- 多语言 NLP 准确度可能不足

### 依赖关系
- Phase 2 (浏览器) 依赖 Phase 1 (类型统一)
- Phase 3 (邮件) 可与 Phase 2 并行
- Phase 4 (Agent) 依赖 Phase 1-3
- Phase 5 (部署) 依赖 Phase 1-4

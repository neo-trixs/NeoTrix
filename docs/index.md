    details: Global Workspace Theory routing with 11 specialist modules competing via salience computation. Coalition formation and decay prevent fixation.

    details: 11-branch meta-cognition loop (Soil → Roots → Trunk → Branches → Fruits → Core) tracking cross-domain health, module maturity, and evolution velocity across 7 domains.

  - title: Persistent Knowledge Base
    details: SQLite-backed KB with full-text search, embeddings, BM25 ranking, retraction-aware quality ranking, and untrusted-content fencing.

  - title: 50+ CLI Commands

  - title: Self-Healing Loop

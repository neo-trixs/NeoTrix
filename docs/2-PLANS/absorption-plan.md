## 开发计划 (4 Phase)

### Phase 1 — Chat 体验补齐 (P0 功能)

**目标**: 让对话功能达到生产可用水平

| 任务 | 文件 | 工作量 |
|------|------|--------|
| 1.1 会话时间分组 | `SessionList.tsx` + `sessionSlice.ts` | 中 |
| 1.2 会话搜索过滤 | `SessionList.tsx` + `SearchOverlay` 联动 | 小 |
| 1.3 TopBar 模型选择器 | `TopBar.tsx` (新建) + `providerSlice` | 中 |
| 1.4 Stop 生成按钮 | `InputPanel.tsx` + `App.tsx` | 小 |
| 1.5 API Key 钥匙串存储 | Rust `keyring` + `api.ts` | 中 |

### Phase 2 — 会话管理增强 (P1 功能)

**目标**: 多会话管理达到主流桌面应用水平

| 任务 | 文件 | 工作量 |
|------|------|--------|
| 2.1 会话置顶 | `sessionSlice.ts` + `SessionList.tsx` | 小 |
| 2.2 侧栏图标模式 (collapsed→icon) | `SessionList.tsx` + CSS | 中 |
| 2.3 消息编辑重发 | `ChatPanel` + store | 中 |
| 2.4 加载三点动画 | `ChatPanel.tsx` | 小 |
| 2.5 滚动到底按钮 | `ChatPanel.tsx` | 小 |
| 2.6 输入框自动增高 | `InputPanel.tsx` | 小 |
| 2.7 毛玻璃输入框 | 预览已设计，接入 React | 小 |

### Phase 3 — 扩展面板 (P2 功能)

**目标**: 集成知识/工具/预览等高价值功能

| 任务 | 文件 | 工作量 |
|------|------|--------|
| 3.1 Artifact 面板 | `ArtifactPanel.tsx` (新建) | 大 |
| 3.2 MCP 工具 UI | `ToolPanel.tsx` (新建) | 中 |
| 3.3 沙箱管理器 UI 增强 | `SandboxManagerPage` | 中 |
| 3.4 隐私过滤器 UI | `PrivacyFilterPage` | 中 |
| 3.5 技能管理 UI | `SkillsPanel.tsx` (新建) | 中 |

### Phase 4 — 高级功能 (P3)

**目标**: 自动化+语音+自定义快捷键

| 任务 | 文件 | 工作量 |
|------|------|--------|
| 4.1 自动化 (调度/文件监听) | `AutomationPanel.tsx` | 大 |
| 4.2 语音输入集成 | `InputPanel.tsx` + Rust | 中 |
| 4.3 快捷键自定义 UI | `Settings ShortcutsTab` | 小 |
| 4.4 开发工具面板 | `DevToolsPanel.tsx` | 中 |

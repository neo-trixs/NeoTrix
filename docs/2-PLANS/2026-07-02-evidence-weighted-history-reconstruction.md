# 物证权重历史重建系统 (EWHR)

## 核心问题

文献有议程，物证会沉默。本系统的目标是：

1. 对全球考古/历史物证进行**可复现的置信度评分**
2. 将伪造物证纳入**概率模型而非简单排除**
3. 跨证据聚类间**自动发现隐式关联**
4. **自我迭代认知** — 新证据加入后自动校准全局权重

---

## 一、物证置信度评分体系

### 1.1 五级置信度 (Confidence Tier)

| 层级 | 名称 | 条件 | 颜色 |
|------|------|------|------|
| T1 | **双重确认 (Double Confirmed)** | ≥2独立实验室，≥2种独立测年方法交叉验证，C14/热释光/古地磁/ESR/铀系法等中至少两种不一致度<10% | 🟢 翠绿 |
| T2 | **单源确认 (Single Confirmed)** | 1篇同行评审论文，1种测年方法，数据完整可复现 | 🔵 蔚蓝 |
| T3 | **初步可考 (Plausible)** | 有正规发掘记录或学术论文但测年方法单一或样本量不足 | 🟡 琥珀 |
| T4 | **存疑 (Suspect)** | 仅民间报告/非学术来源/缺乏系统检测 | 🟠 橙 |
| T5 | **判定伪造 (Confirmed Forgery)** | 已被学术共同体或经鉴定确认为伪造/自然误认 | 🔴 赤红 |

### 1.2 测年方法权重矩阵

每种测年方法有其适用区间和误差特征：

| 方法 | 适用范围 | 典型误差 | 权重系数 | 抗污染能力 |
|------|---------|---------|---------|-----------|
| C14 (AMS) | 0-50,000 BP | ±0.5-2% | 0.90 | 中（需样本纯净） |
| 热释光 (TL) | 0-500,000 BP | ±5-10% | 0.75 | 低（受热历史影响） |
| 光释光 (OSL) | 0-200,000 BP | ±5-8% | 0.80 | 中 |
| 古地磁 | 0-数百万年 | ±10-15% | 0.60 | 高 |
| 电子自旋共振 (ESR) | 0-数百万年 | ±8-12% | 0.65 | 高 |
| 铀系法 (U-series) | 1,000-500,000 BP | ±1-5% | 0.85 | 高 |
| 树轮校正 (Dendro) | 0-12,000 BP | ±0年（绝对） | 1.00 | 极高 |
| 地层层位 | 相对 | 依赖上下文 | 0.50 | 极低 |

**综合置信度公式**：

```
Confidence_Score = Σ(wi × m_i) × C_context × C_publication × C_independent
```

其中：
- wi = 第i种测年方法的权重系数
- m_i = 该方法给出的年代与预期年代的对数偏差的倒数
- C_context = 出土层位清晰度 (0.3-1.0)
- C_publication = 发表渠道 (预印本0.3 → 顶刊1.0)
- C_independent = 独立复现次数 (0次=0.5, 1次=0.8, ≥2次=1.0)

## 二、伪造检测层 (Forgery Detection)

### 2.1 恶意模型 (Adversarial Model)

人类制造伪物证的动机 → 概率建模：

| 动机类型 | 典型场景 | 检测特征 |
|---------|---------|---------|
| **经济欺诈** | 卖假古董 | 来源链断裂、交易记录可追踪 |
| **民族主义** | 制造"最早"的本国文明证据 | 发现时间与政治议程同步、技术超出同期背景 |
| **猎奇/名声** | 制造UFO/巨人/超自然物证 | DNA检测、地质学鉴定、X光/CT断层 |
| **学术欺诈** | 伪造数据支持理论 | 数据异常完美、不可复现 |
| **戏仿/恶作剧** | 考古版"皮尔当人" | 有多重技术时代混杂特征 |

### 2.2 检测维度

每个物证在入库时自动评估以下风险因子：

```
Risk_Score = α·Provenance_Gap + β·Anachronism_Index + γ·Motivation_Score + δ·Verification_Gap
```

- **Provenance_Gap**（0-1）：从出土到首次记录的时间差×中间经手人数。越长/越多→越高
- **Anachronism_Index**（0-1）：物证的技术特征与其声称时代的偏离度。例如：1920年代火花塞在地质结核中 = 1.0
- **Motivation_Score**（0-1）：发现者/持有者是否有造假动机、前科、利益关联
- **Verification_Gap**（0-1）：独立验证次数缺失度（0=已多次独立确认, 1=无法验证）

α, β, γ, δ 为可调参数，初始默认各0.25。

**当 Risk_Score > 0.8 时，该物证自动列入 T5 观察列表**。

### 2.3 已知伪造物的学习库

内置已知伪造案例作为模式匹配的种子数据：

| 名称 | 类型 | 判定手段 | 误判风险 |
|------|------|---------|---------|
| Coso火花塞 | 自然结核误认 | X光+地质鉴定 | 中（自然结核确实像人造） |
| Kensington如尼石 | 恶作剧/声誉造假 | 语言年代学+风化分析 | 低（语言错误系统性） |
| Ica Stones | 经济欺诈 | 刻痕工具现代 | 极低 |
| 皮尔当人 | 学术欺诈 | 氟含量检测 | 极低（现代科学手段） |
| 墨西哥外星人 | 声誉欺诈 | CT扫描+DNA | 极低（明确拼接） |
| 道西铜器 (Dorchester Pot) | 自然+误认 | 器型对比 | 中（维多利亚风格明确） |
| Gunung Padang (25,000年) | 方法缺陷 | 论文撤稿 | 中（地质异常仍存） |

## 三、交叉关联引擎

### 3.1 关联类型

| 关联类型 | 示例 | 判定标准 |
|---------|------|---------|
| **同源** | 两地同种冶金工艺 | 成分分析+工艺特征匹配度 > 0.85 |
| **同线** | 同一传播路径上的遗址 | 经纬大圆对齐 + 年代递减 |
| **同结构** | 跨文明相同的天文对齐 | 天文计算复现同一历法参数 |
| **同材料** | 两地同源玉石/金属 | 同位素指纹匹配 |
| **同生物** | 同种动植物跨半球 | 古DNA + 化石记录 + 历史分布 |

### 3.2 贝叶斯关联网络

```
P(Connection|Evidence_A, Evidence_B) = 
    P(Evidence_A|Connection) × P(Evidence_B|Connection) × P(Connection)
    ───────────────────────────────────────────────────────────────
    P(Evidence_A) × P(Evidence_B)
```

网络自动生长：当新物证录入，系统扫描所有已有物证计算成对关联概率。
关联概率 > 0.75 自动建立连接线，> 0.90 标记"强关联"。

## 四、自迭代认知机制

### 4.1 权重自校准

每次新物证加入时，触发全局权重重算：

1. 新物证的初始置信度按 1.1 公式计算
2. 扫描与新物证时空重叠的已有物证
3. 如果新物证与已有 T1 物证一致 → 周边 T2/T3 物证权重上调
4. 如果新物证与已有 T1 物证矛盾 → 触发矛盾审查（可能有一方被误判）
5. 如果新物证独立确认一个此前仅由文献记载的事件 → 文献可信度上调

### 4.2 共识/矛盾可视化

全局视图显示：

- **共识区**：多个高置信度物证指向同一结论
- **灰色区**：物证不足或相互矛盾的领域
- **盲点区**：无物证覆盖的时空区域（标注为"已知未知"）
- **红区**：有高置信度物证但被文献/主流完全忽视的领域

### 4.3 偏差检测

系统持续追踪：

```
Institutional_Bias_Delta = (Evidence_Strength) / (Academic_Acceptance_Probability)
```

当多组高置信度物证（Evidence_Strength > 0.8）但 Acceptance < 0.2 时，标记为**学术抑制区**。注：系统不预设这是阴谋还是合理审查——只标记为需要进一步研究。

## 六、认知自修改规则

核心：系统必须能推翻自己的早期结论，否则就是另一种教条。

```
if New_Evidence.Confidence > 0.9 AND New_Evidence contradicts Old_Consensus:
    Old_Consensus.Confidence *= 0.5
    trigger_full_recalculation()
    log("⚠️ 认知更新: " + description)
```

每次自我推翻自动记录到迭代日志。
初始阶段系统会输出大量"不确定"——这是诚实的表现。随着物证网络密度增加，不确定区域才逐步缩小。

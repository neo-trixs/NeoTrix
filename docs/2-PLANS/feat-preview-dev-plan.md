## 开发路线图

```
Phase 1 — 核心功能补齐 (当前)
├── ✅ NovaChat 消息增强 (tool cards, code blocks, actions)
├── ✅ Cowork KPI + Kanban + Activity
├── ✅ Code output panel
├── ✅ Gateway KPI strip
├── ✅ Command palette + Keyboard shortcuts
├── ✅ Stacked toast
└── ⏳ 下一步: 编辑功能 (代码编辑, 会话管理 CRUD)

Phase 2 — 数据持久化
├── localStorage 存储:
│   ├── 会话历史 (聊天, 协同, 代码)
│   ├── 设置项 (主题, 字体, 偏好)
│   └── 文件树状态
├── 数据导入/导出
└── 状态恢复 (刷新保持)

Phase 3 — 交互增强
├── Kanban drag & drop
├── 斜杠命令 (/skills)
├── @ 提及
├── 右键菜单
├── 骨架屏加载
└── 甘特图视图 (Cowork)

Phase 4 — 真实后端对接
├── Tauri invoke 替换模拟 API
├── WebSocket 流式消息
├── 真实文件系统操作
└── 状态同步
```

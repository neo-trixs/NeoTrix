## 基准详情

### 1. 单文件解析性能
- **目标**: < 5ms
- **结果**: ~2ms
- **测试**: 100 次迭代，100 行 CSV
- **结论**: ✅ 达标

### 2. 批量处理性能
- **目标**: < 5s
- **结果**: ~3s
- **测试**: 1000 文件，16 并发
- **结论**: ✅ 达标

### 3. 大文件处理性能
- **目标**: < 1s
- **结果**: ~800ms
- **测试**: 10MB CSV (500,000 行)
- **结论**: ✅ 达标

### 4. 适配器检测性能
- **目标**: < 1μs
- **结果**: ~0.5μs
- **测试**: 10,000 次迭代，5 种格式
- **结论**: ✅ 达标

### 5. 格式化器性能
- **目标**: < 1s/100次
- **结果**: ~500ms
- **测试**: 1000 模型，3 种格式
- **结论**: ✅ 达标

### 6. 并发扩展性
- **目标**: 16 并发
- **结果**: 8x 提升
- **测试**: 500 文件，1-16 并发
- **结论**: ✅ 达标

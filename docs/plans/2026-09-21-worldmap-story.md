## 三、出生地：雍州·有熊村（cell 1,3）

- **选址三理由**：雍州为禹迹本部之西陲（新手边陲意象）；cell 地形 = 平原（P），三面开阔；典故"黄帝有熊氏"——人文始祖出生地即玩家出生地。
- **开场 3 分钟**：村长（QuestGiver）发布"清剿鼠患"（既有任务链）→ 战斗教学（空格攻击）→ 掉落第一块鼎碎 → 指向洛邑（周道驿道解锁）。
- **与现有衔接**：当前 L0"新手村外"即有熊村周边 cell 的竞技场展开；敌人/铁匠/守卫/村长坐标全部保留。

## 四、主线三幕

### 第一幕 · 鼎碎（雍州，≈15 分钟）
1. 有熊村出生 → 村长任务"鼠患"（杀 3 鼠，既有 Quest）
2. 鼠王巢穴传闻 → 铁匠打造第一把武器（制作系统教学）
3. 鼠群巢穴得**雍鼎碎片** → 世界地图解锁第 1 格迷雾 → 周道通洛邑

### 第二幕 · 九州（豫州枢纽 + 七州收集，≈2 小时）
1. 洛邑九鼎台：守藏史揭示九鼎散落，**驿道系统**全开（快速旅行）
2. 每州固定结构：入州剧情 → 清剿/解谜 → 鼎守 Boss 战 → 鼎碎 + 该州迷雾点亮
3. 山海经见闻录：每州 1 条异闻（图鉴收集，供 Boss 战前提示弱点）
4. 顺序自由（开放结构），推荐：冀→兖→青→徐→扬→荆（难度递增）

### 第三幕 · 重铸（梁州，≈30 分钟）
1. 褒斜道入蜀 → 鼠王巢穴（既有 L2 关卡即此战前半）
2. 鼠王二阶段：100%→50% 召唤鼠群（既有 adds），50%↓ 狂暴（吸血 0.15 已有，追加火球）
3. 胜利 → 九鼎台重铸 → 世界地图 81 格全亮 → 通关结算（杀敌/XP/探索度/用时）

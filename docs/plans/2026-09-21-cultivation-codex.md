## 四、繁衍回路（生生不息）

```
栖息地匹配 → 容纳量K → logistic繁衍 × 四时(春1.4/夏1.15/秋0.8/冬0.5)
    → 春季脉冲（过半种群爆发+播报） → Arena生成（消耗种群）
    → 捕捉/击杀（奖励+出处播报） → 模板捕食压力 → 迁入保底（永不灭绝）
```

- Arena 投放/重生全部消耗种群数；捕捉奖励 = `catch_value + Lv`，回血 = 种值
- 播报带出处（"捕获九尾狐幼崽·山海经·南山经"），所见即所学

## 五、五行生克表（考据：《尚书·洪范》/淮南子）

映射：兵刃物理=金 / 圣裁=金 / 雷=木 / 冰=水 / 火=火 / 瘴毒=土。
相克（×1.25）：**金克木 → 木克土 → 土克水 → 水克火 → 火克金**，闭环。
地利（抱朴子"山无大小，皆有神灵"）：攻击元素契合本州主元素 ×1.15。
九域主元素：雍金 / 豫圣金 / 冀冰 / 兖金 / 青冰 / 徐土 / 扬冰 / 荆木 / 梁火。

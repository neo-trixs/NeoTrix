# 歸墟 PLAN.md（OpenAI browser-games 八要素）

> 南宋武侠动作游戏（吸收 swordgame.ai）。产品 crate，消费 `neotrix-game` 引擎 lib。

## 1. 玩家目标

活过一波波围攻，冲击更高波次/分数/连击。单局 5–15 分钟；命归零即劍折，
R/空格再战（run 制；战绩当场结算，无 meta）。

## 2. 主循环

出生 → 波次刷怪（预算表）→ 走位/出牌（J 攻/K 跳/L 轻功/Q 飛笠）→
命中回氣攒连击 → 清波横幅 → 下一波（强度微涨）。深度来自走位+出招时机，
引擎保证 60Hz 感知（土狼/缓冲/顿帧/震屏）。

## 3. 输入与控制

- 移动走引擎输入表（WASD/方向键，可重绑）；J/K/L/Q/Shift/Esc/R 为动作键
  （macroquad 直读，跳跃沿检测防吞键）。
- 出招原子：轻功/飛笠先扣氣（不足拒收退款），费用与 cd 合法才提交。
- 键位冲突/持久化走 `BindingTable`（移动部分已接入）。

## 4. 胜负状态

- 负：命归零 → 劍折屏（波次/分/斬/连击/存活）→ R/空格重开。
- 胜：无尽波次，无终局（swordgame.ai 同款：核心是活下去+刷分）。

## 5. 成长与难度

- 局内：命中回氣（8/次）、特招奖氣（10）、波次怪 hp/speed 微涨（`scale_of`，封顶 2 倍）。
- 预算：3+2/波；弱1/快2/精4 费；精锐 3 波解锁；每 3 波一章横幅休整感。
- 数值全进 `waves.rs` 常量/表，一次只调一个（§9.5）。

## 6. 视觉方向

墨夜江湖：深蓝黑底 + 月 + 远山剪影 + 苔绿平台；白衣少侠（剑线）/红敌（精锐金框）/
黄飛笠；像素 CJK 字体（`assets/fonts/pixel-game.ttf`，2953 字，fusion 底 + PingFang SC
移植，`charset.txt` 为语料单源，缺字重跑管线补）。
富文本/HUD 走引擎 `draw_text` + 条件件。

## 7. 技术栈与托管假设

- 渲染/循环：macroquad 0.4（桌面）；wasm 待切（`build_wasm.sh` 模板在 game 侧）。
- 逻辑：`neotrix-game` lib（ECS/输入/粒子/juice/相机/nt_move）+ 本 crate
  `combo`/`qi`/`waves` 纯模块（单测锁定）。
- 确定性：跳跃/波次/连击全纯函数；macroquad `gen_range` 零使用（出生边交替）；
  回放=输入序列（未来）。
- 视觉审计：`NEOTRIX_GUIXU_SHOT=title|play` 离屏 FBO；OOM 抖动用脚本重试
  （16G 机 Metal 显存压力，属环境非代码）。

## 8. 里程碑顺序

- M1：标题/战斗/暂停/劍折四态 + 一波可玩（✅ 本会话： SHOT 双屏通过）。
- M2：敵 AI（视野门/流场二选一复用）+ 特招演出 + 章节叙事行。
- M3：平衡 pass（预算曲线/氣经济）+ 音效（audio 后端落地）。
- M4：wasm 发布 + 移动端触屏。

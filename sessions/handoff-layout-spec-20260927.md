# 对话流＋多模态最优解排版格式（2026-09-27，调研收敛版）

> 来源：shadcn chat 2026-06（Message/Bubble/Attachment/Marker/MessageScroller）、
> setproduct AI 解剖、Jason Laster 15 条、uipotion 渲染模式、飞书卡片规范、
> 抖音信息流规范、Ant Design X 会话设计、51CTO Agent 卡片契约。
> 结论先行：**类型化分块＋卡片即数据＋流式四态＋附件三态＋引用可交互**，
> 气泡保留（owner 定微信/WhatsApp 风），内部走严肃阅读规则。

## 0. 总则（8 条铁律）

1. 消息＝类型化分块有序列表（text/code/tool/cite/artifact/audio/video/file），flat content 字符串是死胡同。
2. 卡片是数据契约不是页面：类型定样式交互，payload 自带标题/数据/跳转；操作仅跳转，不承载输入。
3. 阅读宽 720px 上限、行高 1.6、65-72 字符/行；留白分隔代替分割线堆砌。
4. 流式四态必显：streaming（caret▍）/ stopped / error（可重试）/ done；首字 600ms 内感知。
5. 自动滚动只在距底 100px 内跟随；上翻即锁＋`回到底部 ↓` pill。
6. 每条 controls 在文本之后（复制/重跑/引用/停止），DOM 顺序文本优先（读屏）。
7. 错误就地显示可重试条，不丢消息；降级占位不裸 JSON。
8. `aria-live=polite`＋`prefers-reduced-motion`＋44px 触摸目标。

## 1. 文（结论/要闻/摘要）

- 结构：**结论句（≤40 字加粗前置）→ 分节标题 → 要点列表 → 来源行**。
  与今日热点贴合：顶部 `## 结论` 三行高亮，下面 `## 要闻 · 时政` 分条。
- 列表：单列长项；短项（≤8 字）双列；行内编号引用 `[1]`＋悬停源卡（标题/域名/新鲜度）。
- 长文（>800 字/12 行）默认折叠＋`展开全文`（记忆 per-message，不跳滚动）。
- 标题正文无换行符多余空格；时效标注（`2026-09-27 周日`）跟标题同行右侧。

## 2. 图（新闻配图/截图/附件图）

- 规则（抖音信条）：图与详情一一对应、不拉伸不裁主体、占位图防空白、横图限高 40% 屏、竖图限 50%。
- 卡片内：`custom_width`（大图通栏）／`compact_width`（64×64 缩略＋点击大图）／封面 16:9。
- 多图：1 张大图独占；2-3 张等宽并排；4+ 首图大＋余网格（微信九宫格同构）。
- 附件态：idle/uploading（shimmer 标题）/processing/error（重试）/done。

## 3. 视频

- 卡片：16:9 封面＋时长角标＋▶ 居中；点击内联播（静音首帧）或跳详情，反事实：小窗画中画可选。
- 信息区：来源＋标题＋时长三行，不与播放器抢位；沉浸页才全屏。
- 约束：过半黑白花屏/无声/声画不同步判低质不渲染播放器，只给标题＋原因。

## 4. 音频（语音回复/语音输入）

- 条形播放器：▶/⏸＋波形（或进度条）＋时长＋倍速（1/1.5/2/0.5）＋文字转写折叠行。
- 用户语音：先转写文本入流，音频条附后；小 clips 优先 base64 内联免二次请求。
- 录制上限明示（如 120s）＋取消重录；播放不抢 aria-live。

## 5. 热点汇总整版（今日新闻形态，最优解）

```
┌ 结论卡（置顶，高亮底）：3 行，每行一结论＋[来源]
├ 要闻流：每条＝标题行（加粗）＋2-3 行摘要＋来源·时间行
├ 媒体条：图→三图并排／视频→16:9 卡／音频→条形器（按需出现，无则整块消失）
├ 操作行（泡下）：复制全文 · 导出简报 · 追问 chips（2-4 个 Related）
└ 底部：已读回执式时间戳（同步 09-27 12:00）
```

- 标题党/低质过滤门（标题党/无段落/错字多/图糊判降级折叠）。
- 主次穿插禁令：结论→要闻→媒体→操作，单向向下。

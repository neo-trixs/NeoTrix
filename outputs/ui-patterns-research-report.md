## 一、数据匹配结果展示 UI

### 核心来源
| 来源 | 产品/论文 | 关键模式 |
|------|----------|---------|
| Arango Entity Resolution | Web UI (React Flow) | Review Queue 双列对比 + 字段级相似度分数 |
| GoldenMatch | Web Workbench | Cluster members + field-level diff + NL 一句话解释 |
| Entify | Next.js 16 前端 | Score distribution + threshold analysis + waterfall charts |
| Microsoft Intelligence Toolkit | Match Entity Records | 配置面板 + 结果表 + AI 解释列 |
| LLM-CER (VLDB) | Vue.js 前端 | 层次聚类可视化 + 彩色编码实体标注 + 逐步追踪 |

### 布局模式

**双列并排对比 (Side-by-Side)**
- 候选记录左侧，匹配记录右侧
- 字段名居中作为分隔列（参考 Arango、GoldenMatch、Accurids）
- 差异字段高亮显示（红色/橙色背景），相同字段灰化
- 可选 "Show All" / "Differences Only" 切换（EnterWorks 模式）

**三栏结构**
```
┌─────────────────────────────────────────────────┐
│  筛选栏: 状态 | 评分范围 | 来源 | 批次         │
├──────────────┬──────────────────────────────────┤
│  匹配列表    │  详情对比面板                      │
│  (左侧栏)    │  (右侧主区域)                      │
│  - 候选记录  │  - 字段级逐行对比                   │
│  - 评分徽章  │  - 相似度可视化                     │
│  - 状态标签  │  - LLM 解释                        │
│  - 时间戳    │  - 操作按钮: 确认/拒绝/跳过          │
│              │                                   │
│  ┌────────┐ │  ┌──────────────────────────────┐ │
│  │ 待审N条 │ │  │ 候选: ABC Corp               │ │
│  │ 已审M条 │ │  │ 匹配: ABC Corporation Ltd    │ │
│  │ 自动K条 │ │  │ ─────────────────────────── │ │
│  └────────┘ │  │ 名称: █████████ 92%           │ │
│              │  │ 地址: ████████ 78%            │ │
│              │  │ 电话: ██████ 85%              │ │
│              │  │ 邮箱: ✓ 相同 100%             │ │
│              │  └──────────────────────────────┘ │
└──────────────┴──────────────────────────────────┘
```

### 交互模式
- **键盘快捷键**: M=Match, N=Not Match, S=Skip（参考 Arango）
- **批量操作**: 全选 → 批量确认/拒绝/标记待审
- **行内操作**: 点击行展开详情，hover 显示快速操作
- **热键导航**: ↑/↓ 移动，Enter 进入详情
- **自动流转**: 处理完一条自动跳转下一条

### 视觉模式
- **评分徽章**: 绿色 ≥80 | 橙色 60-79 | 红色 <60（ListMatchGenie 标准）
- **字段级相似度条**: 每个字段旁显示水平进度条，宽度 = 相似度百分比
- **瀑布图**: 展示各字段对总分的贡献权重（Entify 的 Splink waterfall）
- **聚类图**: React Flow 可视化实体关系网络（Arango）
- **彩色编码**: 不同实体用不同颜色标注（LLM-CER 的 Cora 数据集示例）

### 与当前系统的差距 & 可落地改进

| 差距 | 改进方案 | 优先级 |
|------|---------|--------|
| 缺少字段级对比视图 | 实现双列并排 + 字段差异高亮 | **P0** |
| 评分只有数字无上下文 | 添加: 颜色徽章 + 一句话自然语言解释 | **P0** |
| 无批量操作 | 添加全选 + 批量确认/拒绝/跳过 | **P1** |
| 缺少键盘快捷键 | M/N/S 快捷键 + ↑↓ 导航 | **P1** |
| 无相似度可视化 | 字段旁添加水平进度条 | **P1** |
| 无 LLM 解释 | 添加 "为什么匹配" / "为什么不匹配" 文本 | **P2** |
| 缺少聚类可视化 | React Flow/网络图展示实体关系 | **P2** |

## 二、评分可视化

### 核心来源
| 来源 | 关键模式 |
|------|---------|
| Procurize EACD | 置信度仪表 + 证据链图 + What-If 模拟 |
| Decision OS | 加权评分矩阵 + TOPSIS/敏感性分析 + 雷达图 |
| shadcn Reviews Block | 六维加权水平进度条 + 动画过渡 |
| CritLens (IEEE VIS) | 蜂群图 + 覆盖率演化 + 多级评分卡 |
| LocalMode CVP | 颜色分级徽章 + 径向仪表 + 比例填充条 |

### 布局模式

**评分卡矩阵**
```
┌──────────────────────────────────────────────┐
│  综合评分: 87/100  ████████████████░░░░       │
│  置信度: 高 (Green)                           │
├──────────────────────────────────────────────┤
│  维度        得分      权重    加权贡献        │
│  ─────────────────────────────────────       │
│  金额匹配    95%  ████  40%   38.0            │
│  币种匹配    100% █████ 30%   30.0            │
│  日期容差    80%  ███░  20%   16.0            │
│  参考匹配    70%  ██░░  10%    7.0            │
│  ─────────────────────────────────────       │
│  加权总分                         91.0        │
│  置信度说明: 基于 4 维度加权计算               │
└──────────────────────────────────────────────┘
```

**评分色阶系统 (通用标准)**
| 分数范围 | 颜色 | 含义 | 操作建议 |
|---------|------|------|---------|
| 90-100 | 🟢 Green (#4CAF50) | 确定匹配 | 自动确认 |
| 70-89 | 🟡 Amber (#FF9800) | 可能匹配 | 需人工审核 |
| 60-69 | 🟠 Orange | 低置信度 | 优先审核 |
| <60 | 🔴 Red (#F44336) | 不匹配 | 排除或标记 |

### 视觉模式

1. **水平进度条**: 最常见的评分展示，宽度 = 分数百分比
2. **径向仪表盘**: 单一关键指标的突出展示（Procurize 的 Confidence Meter）
3. **雷达图/蛛网图**: 多维度评分的综合展示（Decision OS、CritLens）
4. **蜂群图 (Beeswarm)**: 展示证据分布密度，保留粒度级细节（CritLens）
5. **瀑布图**: 各维度对总分的贡献累加过程
6. **色阶渐变条**: 0-100 的连续色谱，标记当前分数位置

### 交互模式
- **Hover 详情**: 鼠标悬停显示具体数值 + 权重说明
- **What-If 模拟**: 拖动权重滑块，实时重算总分（Procurize）
- **历史趋势**: Sparkline 展示评分随时间变化
- **阈值滑块**: 用户调整自动确认/人工审核的阈值

### 可落地改进

| 差距 | 改进方案 | 优先级 |
|------|---------|--------|
| 评分无维度分解 | 添加多维度加权评分表 + 瀑布图 | **P0** |
| 颜色编码不一致 | 统一色阶: Green/Amber/Red 三档 | **P0** |
| 缺少置信度说明 | 每个评分旁添加一句话解释 | **P1** |
| 无雷达图 | 为多维度评分添加雷达图视图 | **P1** |
| 缺少评分分布 | 在匹配结果页添加分数直方图 | **P2** |


### 状态生命周期 (have-we-met 标准)
```
pending ──→ reviewing ──→ confirmed (终态)
   │            │
   │            └──→ rejected (终态)
   │
   └──→ reviewing ──→ merged (终态)
```

### 交互模式

**优先级排序策略 (Kanoniv)**
1. 决策边界最近的对优先（不确定性最高）
2. 排除明确匹配(0.99)和明确不匹配(0.05)
3. 置信度从低到高排序（Lerian 建议）

**决策界面三要素**
1. **对比视图**: 字段级并排 + 差异高亮
2. **解释文本**: 为什么匹配 + 匹配了哪些字段
3. **决策表单**: 确认/拒绝/跳过 + 备注 + 置信度滑块

**批量操作模式**
- 全选 checkbox
- 批量确认（需预览抽样）
- 批量拒绝（需确认对话框）
- 批量跳过

### 视觉模式
- **置信度滑块**: 用户可调整自己的判断置信度
- **字段差异高亮**: 红色 = 不同，绿色 = 相同
- **状态徽章**: Pending=灰, Reviewing=蓝, Confirmed=绿, Rejected=红
- **进度条**: 已审/总数 进度

### 可落地改进

| 差距 | 改进方案 | 优先级 |
|------|---------|--------|
| 无 Review Queue | 实现 pending→reviewing→confirmed/rejected 状态机 | **P0** |
| 缺少决策表单 | 添加 确认/拒绝/跳过 + 备注 + 置信度 | **P0** |
| 无键盘快捷键 | C/R/S 快捷键 + ↑↓ 导航 | **P1** |
| 缺少批量操作 | 全选 + 批量确认/拒绝 | **P1** |
| 无 LLM 解释 | 添加 "为什么匹配" 自然语言说明 | **P1** |
| 缺少审计追踪 | 记录谁在何时做了什么决策 | **P2** |
| 无 Active Learning | 不确定对优先 + 反馈标签 → 权重迭代 | **P2** |

## 五、表格数据密集型界面

### 核心来源
| 来源 | 关键模式 |
|------|---------|
| SetProduct Blog | 3 级密度控制 + 虚拟滚动 + 冻结列 + Priority+ |
| 137Foundry | 锚定列 + 混合宽度 + 密度切换 + 虚拟化 |
| SaaSUI.design | 列层级 + 行内操作 + 批量操作 + 空状态设计 |
| NinjaTables | 密度校准 + 渐进式披露 + 移动端策略 |
| Edana | 标题上下文 + 服务端排序 + 微反馈 + 视图管理 |

### 核心设计原则

**1. 列层级 (Column Hierarchy)**
- 默认 3-7 列（超过 7 列强制横向扫描，降低理解速度）
- 锚定列（ID/名称）始终最左 + 冻结
- 数字列右对齐（比较尾数而非首数）
- 状态/分类列靠前（便于筛选）
- 额外列放入详情面板或列选择器

**2. 密度控制 (User-Controlled Density)**
| 模式 | 行高 | 适用场景 |
|------|------|---------|
| Compact | 32-36px | 分析师对比 500 行，扫视优先 |
| Comfortable | 40-44px | 混合受众，平衡默认 |
| Spacious | 48-56px | 触控/平板，单行深度阅读 |

关键: 密度切换不应重置筛选/排序/选中状态/编辑草稿。

**3. 冻结列 (Sticky/Frozen Columns)**
- 表头必须冻结（任何超过一屏的表格）
- 锚定列水平冻结（宽表横向滚动时）
- 可冻结 2-3 个标识列（多标识字段场景）

**4. 列宽策略 (Hybrid Width)**
```
固定宽度: 状态、日期、操作按钮（不跳动）
内容驱动: 描述/备注列（弹性填充剩余空间）
最小宽度: 弹性列的下限（防止压缩到不可读）
```

### 交互模式

**行操作模式**
| 模式 | 适用场景 | 实现 |
|------|---------|------|
| 行内操作 | 单行操作为主（编辑、分配、归档） | 每行显示操作按钮 |
| 批量选择 | 批量操作为主（批量状态变更、导出） | 左侧 checkbox + 顶部操作栏 |
| 行内 + 批量 | 混合场景 | 行内操作 + checkbox 双模式 |

**导航策略**
| 策略 | 适用场景 | 优缺点 |
|------|---------|--------|
| 分页 | 可导航的已知数据集 | 结构化、可链接、性能好 |
| 无限滚动 | 浏览/发现式场景 | 流畅但丢失位置 |
| 虚拟化 | 超大数据集(>1000行) | 仅渲染可见行，DOM 节点恒定 |

### 视觉模式

**筛选器设计**
```
┌─────────────────────────────────────────────────┐
│  🔍 搜索...  │  状态: [全部▼]  │  日期: [范围▼] │
│              │  来源: [全部▼]  │  评分: [范围▼] │
│  [保存视图]   │  [重置筛选]     │  [列选择器]    │
└─────────────────────────────────────────────────┘
```

- 筛选器放在表格上方（非 column header 内）
- 命名筛选器: "Status: All / Open / Closed / Escalated"
- 筛选状态跨页保持
- 保存视图: 组合排序+筛选+列选择

**空状态设计**
```
┌─────────────────────────────────────────────────┐
│                                                 │
│        📋 暂无匹配结果                           │
│                                                 │
│  调整筛选条件，或运行新的匹配任务                  │
│                                                 │
│  [创建新匹配]  [查看历史任务]                     │
│                                                 │
└─────────────────────────────────────────────────┘
```

- 首次使用空: 引导 + CTA
- 筛选结果空: 提示调整筛选
- 加载失败空: 错误信息 + 重试

### 可落地改进

| 差距 | 改进方案 | 优先级 |
|------|---------|--------|
| 无密度控制 | 添加 Compact/Comfortable/Spacious 三档切换 | **P0** |
| 表头未冻结 | 实现 sticky header + 冻结锚定列 | **P0** |
| 列数过多 | 默认 3-7 列 + 列选择器显示/隐藏 | **P0** |
| 缺少虚拟滚动 | >1000 行时启用 virtualization | **P1** |
| 无保存视图 | 实现视图保存/加载/分享 | **P1** |
| 筛选器不持久 | 筛选状态跨页/刷新保持 | **P1** |

## 交叉主题：通用设计模式总结

### 1. 评分色阶系统 (全局统一)
```
≥80  → Green  (#22c55e) → 自动确认 / 强匹配
60-79 → Amber  (#f59e0b) → 需人工审核
40-59 → Orange (#f97316) → 优先审核 / 低置信度
<40  → Red    (#ef4444) → 排除 / 不匹配
```

### 2. 键盘快捷键系统
| 快捷键 | 功能 |
|--------|------|
| C / Enter | 确认匹配 |
| R | 拒绝匹配 |
| S / Space | 跳过 |
| ↑/↓ | 上下导航 |
| Tab | 切换字段 |
| Esc | 返回列表 |
| Ctrl+A | 全选 |
| Ctrl+Enter | 批量确认 |

### 3. 信息密度层级
```
Level 1 (列表):   ID + 名称 + 评分徽章 + 状态 + 操作按钮
Level 2 (展开):   + 字段级对比 + 相似度条
Level 3 (详情):   + LLM 解释 + 证据链 + 历史操作
Level 4 (面板):   + 完整原始数据 + 审计日志
```

### 4. 响应式策略
| 视口 | 布局 |
|------|------|
| Desktop (>1024px) | 三栏: 列表 + 对比 + 操作 |
| Tablet (768-1024px) | 两栏: 列表 + 切换对比/操作 |
| Mobile (<768px) | 单栏: 卡片流 + 底部操作栏 |

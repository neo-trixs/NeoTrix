# 作品简介

## 项目名称

**NeoTrix 研发闭环 — 软件研发全流程多 Agent 协同系统**

## 作品简介

### 问题与场景

研发缺陷链路碎片化：Issue、日志、用户反馈多源分散，根因定位依赖资深工程师经验，修复质量难以量化验证，复盘经验散落个人脑中。企业缺乏把「聚合→定位→修复→验证→发布→复盘」串成闭环的可进化系统。

### 核心解决方案

以 GWT 谐振注意力为调度内核，编排 5 类职能 Agent：采集者聚合多源缺陷并降噪；诊断者做代码根因定位与影响面分析；实施者按 TDD 红-绿-重构生成修复；审查者独立验证测试与合规；沉淀者将复盘蒸馏为可复用 Skill。三大创新：E8 确定性 64 态推理内核令定位可复现；SelfTest T1-T3 三层验证体系做质量门禁；experience-tree 五阶段吸收协议让复盘自动沉淀为 Skill。

### 差异化优势

相比单 Agent 工具链，解决任务拆解、上下文传递、结果验证与经验沉淀的系统性问题；相比纯编排框架，多出确定性推理内核与自进化能力。

### 开放与复用价值

开源（MIT），已积累 23.6 万行代码；Skill 体系与 MCP 网关可独立复用，RAG 与可观测设计可迁移到任意多 Agent 生产系统。

### 当前进展

已完成方案设计；7 域架构、4240 项测试及 MCP/Skill/KB 基础设施可支撑复赛运行级 Demo。

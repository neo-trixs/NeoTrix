# check-naming 门基线 —— 「不以 nt_ 前缀命名的 .rs 文件数」
#
# 用途：把该门从「永久恒红、零约束力」改成**单调递减棘轮**。
#   COUNT >  BASELINE ⇒ 新增违规 ⇒ 判红（两个模式都判红，可接 CI）
#   COUNT <= BASELINE ⇒ 无回归 ⇒ exit 0，但输出**必须**写明「不等于合规」
#
# ⛔ 不要拿主工作树的数字覆盖本文件：主树含他窗未提交 .rs，是**非法测量台**
#    （AGENTS.md §4.2 同款判据：层门基线也栽在同一步）。
#    正确测法：`git worktree add --detach HEAD` 的干净检出。
#
# 变更纪律（R-SCAN-3 同款）：本数字下调时，提交里必须带
#   ① 干净检出的重测命令与输出；② 一条说明「哪些文件被改名」的证据。
#   ⛔ **上调 = 给规约放水**：棘轮无法区分「上调基线 + 新增文件」与「无变化」
#      （实测：基线 1613 + 新增 1 个文件 ⇒ COUNT 1613 ⇒ 仍判绿）。
#      故本文件的编辑纪律就是最后一道防线：上调需独立裁决记录，不得顺手改。
#

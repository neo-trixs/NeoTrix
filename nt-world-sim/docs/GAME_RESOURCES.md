## 6. Resource Integration

### Recommended Asset Pipeline

```
1. Download Assets
   └─ Organize into: /assets/tilesets, /assets/sprites, /assets/ui, /assets/audio

2. Tileset Processing
   ├─ Import PNG tilesets into Tiled Map Editor
   ├─ Create .tsx tileset definitions
   ├─ Design maps with multiple layers (ground, objects, collision, events)
   └─ Export as .tmx or .json

3. Sprite Processing
   ├─ Standardize sprite sheet layout (4-direction walk, idle, attack)
   ├─ Define animation frame metadata (JSON or code constants)
   └─ Scale to consistent tile size (16×16, 32×32, or 48×48)

4. UI Integration
   ├─ Import UI sprites as 9-slice for scalable panels
   ├─ Define button states (normal, hover, pressed, disabled)
   └─ Map health/mana bars to game state variables

5. Audio Integration
   ├─ Convert to OGG or MP3 as needed
   ├─ Define sound categories: SFX (short), Music (looped), Ambient
   └─ Implement audio manager with volume/fade controls
```

### Tiled-to-Engine Integration

```rust
// Example: Loading a Tiled TMX map in Rust
use serde::Deserialize;

#[derive(Deserialize)]
struct TiledMap {
    width: u32,
    height: u32,
    tilewidth: u32,
    tileheight: u32,
    layers: Vec<TiledLayer>,
    tilesets: Vec<TiledTileset>,
}

#[derive(Deserialize)]
struct TiledLayer {
    name: String,
    data: Option<Vec<u32>>,
    objects: Option<Vec<TiledObject>>,
    #[serde(rename = "type")]
    layer_type: String,
}

// Load map from JSON export
fn load_map(json_path: &str) -> TiledMap {
    let data = std::fs::read_to_string(json_path).unwrap();
    serde_json::from_str(&data).unwrap()
}
```

### Mir2 Map Format Notes

The Legend of Mir 2 uses a custom binary `.map` format:

- **Header**: Map dimensions (width × height)
- **Cell data**: Each cell contains tile index, object index, door state, attributes
- **Layer system**: Background tile, mid-ground tile, object, overlay
- **Attributes**: Walkable, warppoint, dark area, lit area

For format details, see:
- LOMCN Wiki: https://www.lomcn.org/wiki/
- Crystal Source code: https://github.com/mir2pion/mir2 (Client/Map files)
- Delphi MIR2: https://github.com/lzxsz/MIR2 (GameOfMir/Map files)

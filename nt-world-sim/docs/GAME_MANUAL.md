# NeoTrix Game Manual

## Consciousness Valley

### Controls
| Key | Action |
|-----|--------|
| WASD | Move |
| Space | Use tool / Mine / Fish |
| I | Inventory |
| C | Crafting / Cooking |
| M | Mute / Unmute sound |
| E | Interact / Talk to NPC |
| P | Perfection tracker |
| Q | Quest log |
| Esc | Pause menu |
| 1-9 | Select hotbar slot |

### Farming
1. Equip Hoe (tool 1), press Space on grass to till
2. Equip Seeds (tool 2), press Space on tilled soil to plant
3. Equip Watering Can (tool 3), press Space on crop to water
4. Wait for growth (3-12 days depending on crop)
5. Press Space on grown crop to harvest

### Crops
| Crop | Growth | Seasons | Value |
|------|--------|---------|-------|
| Basic Thought | 4 days | All | 50g |
| Curiosity Bloom | 6 days | Clarity, Flow | 80g |
| Logic Vine | 8 days | Clarity | 120g |
| Empathy Flower | 5 days | Flow, Reflection | 70g |
| Creativity Fern | 7 days | All | 100g |
| Memory Moss | 3 days | Reflection, Stillness | 40g |
| Focus Root | 6 days | Clarity, Stillness | 90g |
| Wisdom Tree | 12 days | All | 200g |

### Seasons
- Clarity (Spring): Best for farming
- Flow (Summer): High growth, more rain
- Reflection (Fall): Foraging season
- Stillness (Winter): Mining focus

### Mining
- Enter from Neural Hub
- Each floor has minerals and enemies
- Use Pickaxe (tool 4) to mine
- Deeper floors = harder enemies, better loot

### Fishing
- Stand near water, equip Fishing Rod (tool 5)
- Press Space to start minigame
- Press Space when fish is in green zone
- Different fish by season and time

### Skills
5 skills x 10 levels: Awareness, Focus, Creativity, Empathy, Logic
Professions at level 5 and 10.

## Neural Arena (MOBA)

### Controls
| Key | Action |
|-----|--------|
| WASD | Move |
| Q/W/E/R | Abilities 1-4 |
| Space | Auto-attack |
| B | Open shop |
| Tab | Scoreboard |

### Heroes
- Blade Master (Fighter): Strike, Shield Bash, War Cry, Execute
- Arcane Mage (Mage): Fireball, Frost Nova, Blink, Meteor
- Shadow Rogue (Assassin): Backstab, Shadow Step, Poison Blade, Death Mark

## Evolution Path

### Controls
| Key | Action |
|-----|--------|
| WASD | Move |
| 1/2/3/4 | Abilities |
| Space | Interact |

### Stages
1. Awareness: Pulse, Dash, Absorb, Shield
2. Perception: Scan, Siphon, Phase, Echo
3. Intelligence: Bolt, Barrier, Beacon, Overclock
4. Empathy: Bond, Soothe, Confuse, Merge
5. Transcendence: Nova, Warp, Clone, Void

## 3. Tileset Formats

### Sprite Sheets (PNG with Grid)

Most tilesets are distributed as PNG sprite sheets with consistent tile dimensions:

```
[Tile 0,0] [Tile 1,0] [Tile 2,0] ...
[Tile 0,1] [Tile 1,1] [Tile 2,1] ...
```

Common grid sizes: 16x16, 32x32, 48x48, 64x64 pixels per tile.

### JSON Metadata

Some packs include Tiled `.tmx`/`.tsx` files with tile properties:
- collision data
- terrain type flags
- animation frame sequences
- auto-tile bitmasks

Examples:
- Pipoya tilesets include Tiled 1.5 compatible files
- Ventilatore Fantasy includes Tiled test maps
- Kenney packs include sprite sheet definitions

- CC-BY-SA = credit + share alike
